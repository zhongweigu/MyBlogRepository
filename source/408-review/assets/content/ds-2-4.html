特殊矩阵压缩存储的核心不是“背一张图”，而是回答两个问题：原来矩阵里哪些位置有值、这些值按什么顺序塞进一维数组。只要能把二维下标 $(i,j)$ 映射成一维下标 $k$，就完成了压缩。

一、二维数组的地址计算

设二维数组 $A$ 有 $m$ 行、$n$ 列，元素大小为 $L$，首元素 $A[0][0]$ 的地址为 $LOC(0,0)$，下标从 0 开始。

存储方式地址公式理解
行优先$LOC(i,j)=LOC(0,0)+(i\times n+j)\times L$先存完前 $i$ 行（每行 $n$ 个），再存本行前 $j$ 个
列优先$LOC(i,j)=LOC(0,0)+(j\times m+i)\times L$先存完前 $j$ 列（每列 $m$ 个），再存本列前 $i$ 个

例：$m=3,n=4,L=4$，行优先时 $A[1][2]$ 的偏移是 $(1\times4+2)\times4=24$ 字节；列优先时是 $(2\times3+1)\times4=28$ 字节。C 语言二维数组按行优先存储，Fortran 默认按列优先。

二、稀疏矩阵：三元组表与十字链表

稀疏矩阵中非零元素很少，若仍存整个 $m\times n$ 矩阵会浪费大量空间。常见做法是只存非零元素：

  • 三元组表：每个非零元存 `(i, j, value)`，通常再存总行数、总列数、非零元个数；可按行优先排列，也可按列优先排列。
  • 十字链表：每个非零元结点含行、列、值、行指针、列指针；每行/每列各有一个头结点，形成十字交叉的链表。

三元组表顺序存储、结构简单；十字链表用指针换灵活，适合非零元动态变化。若题目只问“怎样压缩”，先答三元组表；若问“插入/删除方便”，答十字链表。

三、对称矩阵

对称矩阵满足 $A[i][j]=A[j][i]$，因此只需存下三角（含对角线）或上三角。以 $n\times n$ 矩阵、行优先存下三角、下标从 0 开始为例：

若 i ≥ j：k = i(i+1)/2 + j
若 i < j：交换 i、j 后代入上式（利用对称性）

例子：$n=4$，$A[2][1]$ 的下标 $k=2\times3/2+1=4$；$A[1][2]$ 利用对称性等价于 $A[2][1]$，也存到 $k=4$。一维数组只需 $n(n+1)/2$ 个元素，而不是 $n^2$ 个。

四、三角矩阵与三对角矩阵

下三角矩阵（上三角全为常数 $c$）：下三角部分与对称矩阵的下三角公式相同，$k=i(i+1)/2+j$；最后再单独存一个常数 $c$，数组长度 $n(n+1)/2+1$。

上三角矩阵（下三角全为常数 $c$）：按行优先存上三角，第 $i$ 行从 $j=i$ 到 $n-1$，前面共有

k = i*n - i(i-1)/2 + (j-i)     // i ≤ j
数组长度 = n(n+1)/2 + 1

三对角（带状）矩阵：只有主对角线及上下各一条对角线非零，即 $|i-j|\le1$。按行优先存这三条带，第 $i$ 行最多 3 个元素：

k = 2i + j        // j = i-1, i, i+1（边界行除外）
数组长度 = 3n - 2

五、易错点与收束

  • “对称矩阵存整个矩阵”：只需存一半，长度约 $n(n+1)/2$，不是 $n^2$。
  • “上三角和下三角公式一样”：下三角按行优先是 $i(i+1)/2+j$；上三角要按它前面的完整行/列重新推，不能直接套。
  • “三对角矩阵有 3n 个元素”：边界两行只有 2 个，长度是 $3n-2$。
  • “稀疏矩阵压缩后一定省空间”：三元组每个元素还要存行、列，非零元很多时不一定省；稀疏才适合压缩。

把这一节收成一句话：二维数组先定行/列优先；对称/三角利用重复元素只存一半；三对角只存三条带；稀疏矩阵用三元组或十字链表存非零元。
