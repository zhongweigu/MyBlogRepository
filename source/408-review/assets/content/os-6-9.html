固态硬盘（SSD）不是“更快的机械盘”，而是用闪存 + 闪存翻译层（FTL）模拟块设备。操作系统仍然按“读/写磁盘块”的方式使用它，但底层的读写单位、擦除方式和寿命管理完全不同。

一、SSD 与机械盘的根本区别

机械盘靠磁头寻道和盘片旋转定位，随机访问要付寻道/旋转延迟；SSD 没有机械运动，随机读由闪存和控制器直接定位，因此随机读延迟低、抗震动，但写操作受“先擦后写”和寿命限制。

维度机械硬盘 HDD固态硬盘 SSD
定位寻道 + 旋转延迟控制器/FTL 映射，无机械寻道
读单位扇区/块页（典型 4KB，因器件而异）
写单位扇区/块，可原地覆盖页编程；不能原地覆盖，需先擦除整块
擦除单位无“擦除”概念块（典型几十到几百页）
寿命机械磨损/磁头故障闪存擦写次数有限，需要磨损均衡

二、结构：总线、FTL、闪存、块、页

SSD 对外表现为一个块设备：主机通过 I/O 总线（SATA、PCIe/NVMe 等）发读写命令；SSD 控制器中的 闪存翻译层 FTL 把逻辑块地址 LBA 映射到闪存的物理页；下层是若干闪存芯片，芯片内部按“块（block）→页（page）”组织。

层次可以记成：主机 → I/O 总线 → SSD 控制器/FTL → 闪存芯片 → 块 → 页。FTL 是 SSD 内部的“地址翻译 + 垃圾回收 + 磨损均衡”层，不是操作系统里的文件系统。

三、读/写以页为单位，擦除以块为单位

  • 读：按页读取；随机读不需要机械寻道，延迟主要来自控制器、闪存读取和队列。
  • 写：按页编程；但闪存页不能像内存那样直接覆盖旧内容。要修改一个已有页，通常先把该块中的有效页复制到新块，再擦除旧块，最后写入新数据。
  • 擦除：以块为单位；擦除次数有限，是 SSD 寿命的核心约束。

因此“写一页”可能引发“读整块有效页 + 写新块 + 擦旧块”的连锁操作，称为写放大。FTL 会尽量把顺序写、合并空闲页，并在后台做垃圾回收（GC）。

四、FTL、映射与垃圾回收

FTL 维护逻辑块地址 → 物理页的映射表。写新数据时，FTL 往往写到新的空闲页，再把逻辑地址改指向新页；旧页变成“无效页”。当空闲块不足时，GC 选择一个块，把其中仍有效的页搬到新块，然后擦除整块回收空间。

这解释了 SSD 的几个现象：

  • 顺序写通常比随机写友好，因为随机写会产生更多无效页和 GC；
  • 盘越满，GC 越频繁，写性能可能下降；
  • TRIM 告诉 SSD 哪些逻辑块已不再使用，减少无意义的有效页搬运；
  • FTL 的映射表需要内存/缓存，掉电保护很重要。

五、磨损均衡：动态与静态

闪存块的擦除次数有限。如果总是反复写同一批块，它们会先坏。磨损均衡把写/擦除分散到不同块，延长整体寿命，并用擦除计数记录每个块的磨损。

方式做法优点/局限
动态磨损均衡只在“正在被写入/可分配”的块之间轮换，冷数据长期不动实现简单；冷数据占用的块几乎不被擦写，磨损分布仍可能不均
静态磨损均衡除了动态轮换，还会主动搬移长期不动的冷数据，让老块也参与轮换磨损更均匀、寿命更长；需要额外搬移，带来写放大和开销

六、性能、可靠性与使用边界

  • 随机读：SSD 的优势场景，不需要寻道/旋转；但受队列深度、控制器和闪存并行度影响。
  • 随机写：受“先擦后写”、GC 和写放大影响，未必比顺序写快；盘满时更明显。
  • 寿命：用 TBW/DWPD 等指标描述；磨损均衡、预留空间（OP）和 TRIM 都会影响实际寿命。
  • 可靠性：没有机械寻道，但闪存有保持时间、坏块、掉电保护等问题；RAID 仍可用于冗余，但不能把 SSD 当成“不会坏”。
  • 调度：HDD 的寻道优化（SSTF/SCAN 等）对 SSD 没有同样的机械意义；SSD 更关心队列、并行度、GC 和写放大。传统磁盘调度算法在 SSD 上通常不再按“减少寻道”来评价。

七、易错点与收束

  • “SSD 按块读写”：读/写的基本单位是页，擦除单位才是块。
  • “SSD 可以原地覆盖写”：闪存页不能直接覆盖，通常要写新页、改映射，旧页等待 GC 回收。
  • “磨损均衡只是按顺序轮换”：动态/静态策略不同；静态会搬移冷数据，代价是额外写。
  • “SSD 不需要文件系统/FTL”：文件系统仍管理逻辑文件，FTL 管理逻辑块到物理页；二者层次不同。
  • “SSD 上 SCAN 一定更好”：没有机械寻道，传统寻道调度收益很小；应关注并行度、GC、写放大和寿命。

收束：SSD = 闪存 + FTL + 块设备接口；读/写按页，擦除按块，靠映射、GC 和磨损均衡把“不能覆盖写、擦除次数有限”的闪存伪装成普通磁盘。
