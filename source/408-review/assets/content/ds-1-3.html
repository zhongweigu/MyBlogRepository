一、数据、数据元素、数据项、数据对象

术语含义例子
数据信息的载体，是描述客观事物的符号集合一张学生表、一段程序、一张图片
数据元素数据的基本单位，通常作为一个整体处理学生表中的一行（一个学生记录）
数据项组成数据元素的不可分割最小单位学号、姓名、成绩
数据对象具有相同性质的数据元素的集合所有学生的记录

关系可以记成：数据对象由数据元素组成，数据元素由数据项组成。数据项不可再分；数据元素是“整体处理”的单位；数据对象是“同类元素”的集合。

二、数据结构的三个要素

数据结构不是“数据 + 结构”这么模糊，它包含三件事：

  1. 逻辑结构：数据元素之间的逻辑关系；
  2. 存储结构：逻辑结构在计算机中的表示；
  3. 数据的运算：定义在该结构上的一组操作。
要素回答的问题常见类型
逻辑结构元素之间是什么关系？集合、线性、树形、图形
存储结构这种关系在内存里怎么放？顺序、链式、索引、散列
数据的运算能对它做什么？插入、删除、查找、遍历

逻辑结构与存储结构要分开看：

  • 线性表是逻辑结构；顺序表和链表是它的两种存储结构。
  • 树是逻辑结构；孩子兄弟表示法、双亲表示法是它的存储结构。
  • 图是逻辑结构；邻接矩阵、邻接表是它的存储结构。

同一逻辑结构换一种存储结构，运算的实现和复杂度都会变。例如“按位查找”在顺序表是 O(1)，在链表是 O(n)；但它们的逻辑结构都还是线性表。

三、抽象数据类型 ADT

抽象数据类型（Abstract Data Type，ADT）是一个数学模型以及定义在该模型上的一组操作。它只规定“数据对象是什么、元素之间什么关系、能做哪些操作”，不规定“用什么存储、怎么实现”。

ADT List {
    数据对象：D = {a_i | a_i ∈ ElemSet, i = 1..n}
    数据关系：除第一个/最后一个外，每个元素有唯一前驱和后继
    基本操作：InitList, DestroyList, Insert, Delete, Locate, GetElem ...
} ADT List

ADT 的价值是把“做什么”与“怎么做”分离：先定义接口语义，再用顺序表或链表实现。408 里常把“顺序表”“链表”当作 ADT 的两种实现来比较。

四、算法与复杂度

算法是对特定问题求解步骤的描述，必须满足五个特性：

特性含义
有穷性有限步后结束，每一步都在有限时间内完成
确定性每条指令含义明确，无二义性；相同输入得到相同结果
可行性每一步都能通过有限次基本运算实现
输入有零个或多个输入
输出有一个或多个输出

“程序”不一定满足有穷性（操作系统就是无限循环），所以程序 ≠ 算法。好算法还要追求正确性、可读性、健壮性、高效率和低存储需求。

时间复杂度看基本操作执行次数随问题规模 n 的增长数量级；空间复杂度看除输入外额外辅助空间随 n 的增长数量级。递归算法的空间复杂度要算递归调用栈的深度。

记号含义例子
O渐进上界3n²+2n+1 = O(n²)
Ω渐进下界n² = Ω(n²)
Θ渐进紧确界3n²+2n = Θ(n²)

常见数量级从小到大：O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2ⁿ) < O(n!)。408 选择题常要求“看循环/递归直接判阶”，具体计数方法见下一考点。
