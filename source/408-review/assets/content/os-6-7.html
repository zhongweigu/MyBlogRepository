一块全新的磁盘不能直接存文件，更不能直接启动操作系统。它要经历物理格式化 → 分区 → 逻辑格式化 → 安装 OS → 建立引导信息几个阶段；每个阶段解决不同层次的问题。这一页把“新磁盘怎样变成可存文件、可启动 OS 的磁盘”串起来，引导链的硬件细节与文件系统布局分别回看 OS 引导、文件系统布局两页。

一、物理格式化：把盘变成扇区

物理格式化（低级格式化）是磁盘出厂/底层维护阶段做的事：在盘面上划分磁道，把每条磁道划分成扇区，写入扇区头、地址标识、校验信息等。它建立的是最底层的存储单位，与文件系统无关。

  • 确定扇区大小（如 512B/4KB）和每道扇区数；
  • 写入扇区间隙、同步字段、纠错码；
  • 坏扇区标记/重映射通常也在这个层次处理。

低级格式化不是“把文件系统装上去”，也不负责目录、inode、空闲空间；它只让磁盘控制器能够按“柱面/磁头/扇区”读写。

二、分区与分区表

分区把整块磁盘划分为若干逻辑区域（C 盘、D 盘等），每个分区可以独立安装文件系统。磁盘的第一个扇区通常存放主引导记录 MBR（传统 BIOS 路径）或 GPT 分区表（UEFI 路径）。

分区表至少记录每个分区的起始位置、大小、类型、是否活动等信息。MBR 分区表与 GPT 的细节不同，但共同点是：分区表是“磁盘级”的，文件系统是“分区级”的。一个分区里可以有独立文件系统，也可以暂时没有文件系统。

三、逻辑格式化：建立文件系统

逻辑格式化（高级格式化）在某个分区内建立文件系统所需的数据结构，例如：

  • 引导块/分区引导记录（PBR）；
  • 超级块：文件系统类型、块大小、inode 数量、空闲空间管理入口；
  • 空闲空间管理结构（位示图/空闲表/成组链接等）；
  • inode 表/根目录；
  • 文件系统使用的逻辑组织和元数据。

逻辑格式化之后，分区才能被操作系统“识别为一个文件系统”，才能执行 open/read/write。它与物理格式化的区别是：物理格式化面向扇区，逻辑格式化面向文件和目录。

分区内的典型布局可回看 文件系统布局与磁盘结构：引导块 → 超级块 → 空闲空间管理 → inode 表 → 根目录 → 数据块。不同文件系统（ext4/NTFS）细节不同，但“元数据区在前、数据区在后”的层次思想相通。

四、安装 OS 与内核初始化

安装操作系统通常做三件事：把内核/驱动/系统文件写入分区；建立引导程序与引导配置；初始化根文件系统。之后每次开机，固件按启动顺序找到引导设备，加载引导程序，再把内核送进内存。

引导链的 MBR/PBR/loader 细节见 OS 引导；这里从“内核开始执行”之后看初始化顺序：

  1. 进入内核并完成基础初始化：设置内核栈、处理器状态、必要的控制寄存器。
  2. 初始化内存管理：确定可用内存，建立内存管理表、内核地址空间，为后续进程/缓冲/驱动提供内存基础。
  3. 初始化中断和异常机制：建立中断向量表/中断描述结构，准备各种异常和中断的处理入口。
  4. 初始化设备和驱动程序：探测/发现设备，初始化控制器，加载或初始化驱动，注册 ISR。
  5. 初始化进程/线程管理与调度器：建立 PCB、运行队列、调度器，为“谁先获得 CPU”做准备。
  6. 初始化文件系统：识别磁盘上的文件系统结构，挂载根文件系统；完成后才能执行 open/read/write。
  7. 创建内核线程和第一个用户进程：启动必要的系统任务，创建第一个用户进程，继续启动系统服务、登录环境或桌面。
  8. 进入正常运营阶段：系统进入日常可用状态。

这八个步骤不是所有 OS 都严格按同一顺序，但“内存/中断/驱动/调度/文件系统/第一个进程”这条依赖链是稳定的：没有内存管理就无法建表，没有中断/驱动就无法响应设备，没有文件系统就无法加载用户程序。

五、易错点与收束

  • “低级格式化 = 高级格式化”：低级建立扇区，高级建立文件系统元数据；层次不同。
  • “分区就是文件系统”：分区是磁盘区域，文件系统是分区内的组织结构；一个分区可以暂时没有文件系统。
  • “MBR 在分区内”：MBR 在磁盘 LBA 0，是磁盘级；PBR 在分区自己的第一个扇区。
  • “安装 OS 就是复制内核文件”：还要建立引导程序/配置、根文件系统、驱动和初始化环境。
  • “内核初始化先启动第一个进程，再初始化文件系统”：通常要先有内存、中断、驱动和文件系统，才能加载/创建用户进程；顺序不能倒。

收束：物理格式化把盘变成扇区，分区把盘分给不同系统，逻辑格式化在分区内建文件系统，安装/引导把内核送进内存，内核再按依赖顺序初始化内存、中断、驱动、调度、文件系统和第一个进程。
