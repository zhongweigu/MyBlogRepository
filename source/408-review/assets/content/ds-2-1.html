链表的操作是常考题，而做插入 / 删除时最容易漏的就是边界情况：要动的结点是不是尾指针指向的那个。

线性表的 ADT 与两种实现

线性表的逻辑特征是“一对一”：除第一个元素外每个元素有唯一前驱，除最后一个外每个元素有唯一后继。ADT 只规定这些操作，不规定底层用数组还是指针：

ADT List {
    InitList(&L)           // 初始化空表
    Length(L)             // 求表长
    LocateElem(L, e)      // 按值查找
    GetElem(L, i, &e)     // 按位查找
    ListInsert(&L, i, e)  // 第 i 个位置插入
    ListDelete(&L, i, &e) // 删除第 i 个元素
    PrintList(L)
} ADT List

顺序表用一段连续存储单元依次存放元素，逻辑相邻 = 物理相邻；链表用结点里的指针表示后继，逻辑相邻 ≠ 物理相邻。静态链表则用数组模拟指针：每个数组元素存 `data` 和 `next`（下标），靠下标串成链。

实现按位查找插入/删除空间适用
顺序表O(1)O(n) 移动元素需要连续空间，可能扩容复制查找多、表长稳定
单链表O(n)已知前驱时 O(1)，否则 O(n) 找前驱每个结点多一个指针频繁插删、动态增长
双链表O(n)已知结点时 O(1) 前插/后插/删除每个结点两个指针需要双向遍历
循环链表O(n)尾结点 next 指回头结点，便于首尾相接同单/双链表约瑟夫环、循环队列链式实现
静态链表O(n)改下标，不移动元素数组大小固定不支持指针的语言/旧教材

单链表插入/删除的指针顺序

在结点 `p` 之后插入 `s`，必须先让 `s->next = p->next`，再 `p->next = s`；顺序反了会把 `p` 原来的后继丢掉。

s->next = p->next;
p->next = s;

// 删除 p 的后继 q
q = p->next;
p->next = q->next;
free(q);

如果要在表头插入，需要修改头指针；如果删除的是尾结点，单链表还要从头找到它的前驱——这正是“带头结点/带尾指针”等设计要解决的问题。双链表删除结点 `p` 时，要同时改 `p->prior->next` 和 `p->next->prior`，并处理 `p` 是首/尾结点的边界。
