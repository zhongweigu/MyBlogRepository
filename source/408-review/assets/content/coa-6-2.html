三种 I/O 方式与 DMA

程序查询、中断、DMA 的核心差别是“谁等、谁搬、CPU 介入到什么程度”。

三种 I/O 方式的流程

程序查询方式

  1. CPU 预置传送参数（内存缓冲区、设备地址、字计数）。
  2. 启动外设。
  3. 读外设状态，判断是否就绪；未就绪就循环查询。
  4. 就绪后传送一个数据，修改内存地址和字计数。
  5. 判断是否传送完；未完继续查询，完成则结束。

独占查询会让 CPU 一直忙等；定时查询是周期性地查，查询间隔与设备传输速率有关。优点是简单，缺点是 CPU 与外设完全串行，浪费 CPU。

中断控制方式

  1. CPU 启动外设后继续执行其他程序，不必等待。
  2. 外设完成一个数据单元后向 CPU 发中断请求。
  3. CPU 在满足条件时响应，转中断服务程序传送数据。
  4. 服务结束返回原程序；下一个数据再重复。

外设与 CPU 可以并行，但每传一个数据仍要一次中断和一段服务程序，适合中低速、随机 I/O。

DMA 控制方式

  1. CPU 初始化 DMA 控制器：内存起始地址、设备地址、传送长度、方向。
  2. CPU 发“启动 DMA”命令，之后不再参与数据搬运。
  3. DMA 控制器申请总线，获得后给出内存地址、发读写命令，在设备与主存之间直接传数据。
  4. 每传一次，地址计数器加 1、长度计数器减 1；计数值为 0 表示完成。
  5. DMA 向 CPU 发“DMA 结束”中断，CPU 做校验等后处理。

DMA 适合磁盘、网卡等成块高速设备；CPU 只在开始和结束介入。

DMA 传送流程与控制器

  1. 预处理：CPU 把主存起始地址送 AR（地址计数器）、设备地址送 DAR、传送长度送 WC（字计数器），启动设备。
  2. 申请总线：DMA 控制器发 HRQ，CPU 响应后发 HLDA，DMA 获得总线控制权。
  3. 传送：DMA 给出主存地址，发读/写命令，在设备与主存之间传数据；每传一次，地址计数器 +1、长度计数器 −1。
  4. 结束：WC=0 时，DMA 发中断请求，CPU 转入中断服务程序做数据校验、结束处理。
  5. 归还总线：DMA 释放总线，CPU 继续执行主程序。

块传输：DMA 面向一整块数据，CPU 设置参数并启动后，整块交给 DMA 控制器；完成后 DMA 用中断通知 CPU。单字传输（周期挪用）：DMA 每次只申请一个总线周期，传一个字/一个基本单位，然后归还总线，下次再申请。两者不是对立关系：块传输是总任务，实际占用总线时可以按单字逐次传。

DMA 与 CPU 争总线的三种方式：停止 CPU 访存（简单但 CPU 长时间不能访存）、周期挪用（最常用）、交替访问（CPU 与 DMA 分时使用总线）。DMA 请求通常在总线周期结束时响应，优先级通常高于中断。

中断与 DMA 的区别

维度程序中断DMA
数据搬运者CPU 执行服务程序DMA 控制器硬件
CPU 介入每次传送都要参与开始 / 结束介入
响应时机指令执行结束后总线周期结束后
适用数据量少量、随机成块、高速
优先级通常低于 DMA通常高于中断

常考判断：中断隐指令由硬件完成；中断响应后 PC 指向服务程序入口；断点现场要保存；DMA 传送不经过 CPU 的通用寄存器；DMA 与中断可以同时存在，但 DMA 请求通常优先级更高。
