考点5-栈的应用

括号匹配

括号匹配要解决三个问题：

  1. 左括号必须用相同类型的右括号闭合；
  2. 左括号必须以正确的顺序闭合；
  3. 每个右括号都有一个对应的相同类型的左括号。

用栈检验，本质是"等待"：每遇到一个左括号就压栈（表示"正在等它对应的右括号"）；这期间如果又来了另一类左括号，就把它当成优先级更高的新任务压上去，转而去等它；一旦遇到与栈顶同类型的右括号，就弹栈、成对消除。

落到代码上：遇左括号入栈；遇右括号，若栈空或栈顶不是同类型左括号 → 不合法，否则弹栈；扫描结束后栈非空也不合法（还有左括号没被闭合）。

例题：【2025】（符号栈容量为 3）

【2025】对于括号匹配问题，符号栈初始为空，容量为 3，不能实现的表达式是

  • A. (a+[b+(c+d)/e]+f)+g−h
  • B. [a*((b+c)/(d−e)+f/g)]−h
  • C. [a*(b−(c−d)*e/(f+g))−h]
  • D. [a−(b+[c*(d+e)−f]+g+h)]
查看答案解析

选 D。 演算方法：从左到右扫一遍，遇左括号栈深 +1、遇右括号栈深 −1，过程中栈深的最大值就是这条表达式需要的容量（顺带核对一下配对类型是否一致）。

  • A：栈深 1 → 2 → 3 → 2 → 1 → 0，最大 3 ✅
  • B：1 → 2 → 3 → 2 → 3 → 2 → 1 → 0，最大 3 ✅
  • C：1 → 2 → 3 → 2 → 3 → 2 → 1 → 0，最大 3 ✅
  • D：1 → 2 → 3 → 4 ✗ 中途就要 4 个格子，容量 3 放不下

所以选 D。

表达式求值

三种表达式求值的对照表：

一、中缀怎么转后缀 / 前缀：画表达式树

  • 运算符按优先级和结合性往下管住它的两个运算对象，画成一棵二叉树：操作数全在叶子上，运算符全在内部结点；
  • 这棵树后序遍历 = 后缀表达式、先序遍历 = 前缀表达式、中序遍历 = 中缀表达式；
  • 所以三种表达式里操作数的相对顺序完全一样（都是原表达式里从左到右的顺序），变的只是运算符插在哪儿；
  • 手算就用「从树底往上合并」：先找优先级最高、最靠里的小单元合成一个整体，再往上接。

以 A+B*(C−D)−E/F 为例：

合并到哪一步 后缀 前缀
C−D C D − − C D
B*(C−D) B C D − * * B − C D
A+B*(C−D) A B C D − * + + A * B − C D
E/F E F / / E F
整体 A B C D − * + E F / − − + A * B − C D / E F

二、代码怎么算（对应上面那张表）：

  • 后缀：从左到右扫；操作数入栈；遇运算符弹出两个（先弹出的是右操作数），算完压回；
  • 前缀：从右到左扫；操作数入栈；遇运算符同样弹两个，但先弹出的是左操作数；
  • 中缀：两个栈（操作数栈 + 运算符栈），遇运算符先把栈里优先级 ≥ 它的都算掉，括号单独处理。

举一个前缀的例子：+ * 3 4 5（即 3*4+5），从右往左扫：

扫到 动作 栈（底 → 顶）
5 入栈 5
4 入栈 5, 4
3 入栈 5, 4, 3
* 弹出 3、4，先弹的是左操作数 → 3×4=12，压回 5, 12
+ 弹出 12、5 → 12+5=17，压回 17

得 17 ✅。

中缀表达式转后缀表达式

从栈的角度看，它和"中缀求值"差不多，区别是不用维护操作数栈：操作数直接输出，栈里只留暂时定不了次序的运算符。

  • 从左到右扫描中缀表达式；
  • 遇到操作数，直接输出；
  • 遇到运算符：依次弹出栈中优先级 ≥ 它的运算符并输出（碰到左括号或栈空就停），最后把当前运算符入栈；
  • 遇到左括号入栈；遇到右括号就一直弹栈输出，直到把那个左括号弹掉为止；
  • 扫描结束，把栈里剩下的运算符依次弹出输出。

例题：【2012】（栈里最多同时存几个运算符）

【2012】已知操作符包括 + - * / ( )。将中缀表达式 a+b-a*((c+d)/e-f)+g 转换为等价的后缀表达式 ab+acd+e/f-*-g+ 时，用栈存放暂时还不能确定运算次序的操作符。栈初始时为空，转换过程中同时保存在栈中的操作符的最大个数是

  • A. 5
  • B. 7
  • C. 8
  • D. 11
查看答案解析

选 A（5 个）。 按规则从左到右走一遍（栈里只放运算符，方括号内从左到右是栈底到栈顶）：

扫到 动作 栈 已输出
a 输出 [] a
+ 入栈 [+] a
b 输出 [+] ab
- + ≥ -，弹出 + 输出；- 入栈 [- ] ab+
a 输出 [- ] ab+a
* - < *，不弹；* 入栈 [- *] ab+a
( 入栈 [- * (] ab+a
( 入栈 [- * ( (] ab+a
c 输出 [- * ( (] ab+ac
+ 栈顶是 (，停；+ 入栈 [- * ( ( +] ← 5 个 ab+ac
d 输出 [- * ( ( +] ab+acd
) 弹到 ( 为止：弹出 + 输出，再弹掉 ( [- * (] ab+acd+
/ 栈顶是 (，停；/ 入栈 [- * ( /] ab+acd+
e 输出 [- * ( /] ab+acd+e

结果与题目给的后缀表达式一致 ✅。过程中栈里最多同时有 5 个运算符（- * ( ( +），选 A。

递归

结合栈看递归，就是看调用过程：最早进入的那次调用在栈底，最新进入的在栈顶；每进入一层压一个栈帧，返回时弹出、恢复上一层。

例题：【2015】（栈底到栈顶是谁）

【2015】已知程序如下：

int S(int n)
{ return (n<=0) ? 0 : S(n-1)+n; }
void main()
{ cout << S(1); }

程序运行时使用栈来保存调用过程的信息，自栈底到栈顶保存的信息依次对应的是

  • A. main() → S(1) → S(0)
  • B. S(0) → S(1) → main()
  • C. main() → S(0) → S(1)
  • D. S(1) → S(0) → main()
查看答案解析

选 A。 调用顺序是 main 调 S(1)、S(1) 内部又调 S(0)，所以自栈底到栈顶就是 main() → S(1) → S(0)：最早进入的压在底下，最后进入的落在顶上。

例题：分析 F(6) 的调用过程

若 F(n) 定义为

int F(int n){
    if (n <= 2) return 1;
    else return F(n-2) + F(n-3) + 1;
}

请分析 F(6) 的调用过程。

查看答案解析

调用树（两个分支，按源码顺序先走 F(n-2)）：

F(6)
├─ F(4)
│  ├─ F(2) = 1
│  └─ F(1) = 1          → F(4) = 1 + 1 + 1 = 3
└─ F(3)
   ├─ F(1) = 1
   └─ F(0) = 1          → F(3) = 1 + 1 + 1 = 3
                        → F(6) = 3 + 3 + 1 = 7

栈的变化（栈底 → 栈顶）：

时刻 动作 栈
1 调用 F(6) F(6)
2 F(6) 调 F(4) F(6), F(4)
3 F(4) 调 F(2) F(6), F(4), F(2)
4 F(2) 命中 n ≤ 2，返回 1 F(6), F(4)
5 F(4) 调 F(1) F(6), F(4), F(1)
6 F(1) 返回 1 F(6), F(4)
7 F(4) 返回 3 F(6)
8 F(6) 调 F(3) F(6), F(3)
9 F(3) 调 F(1) F(6), F(3), F(1)
10 F(1) 返回 1 F(6), F(3)
11 F(3) 调 F(0) F(6), F(3), F(0)
12 F(0) 返回 1 F(6), F(3)
13 F(3) 返回 3 F(6)
14 F(6) 返回 7 空

共 7 次调用，栈最深 3 层，栈底始终是 F(6)。
