分页是按“固定大小的页”切，分段是按“程序逻辑”切：主程序、子程序、数据可以各成一段，段长不等。分段更贴近程序员看到的程序结构，段页式则把“逻辑分段”和“物理分页”合在一起。

一、分段：按逻辑单位切

分段从程序员视角出发，把进程地址空间按逻辑划分为若干段，例如主程序段、子程序段、栈段、数据段。每段大小不等，每段有自己的段名/段号，段内地址从 0 开始。

只有分段的系统，对主存没有任何预先划分：段是进程地址空间的逻辑划分，主存只是按空闲区分配；每个段离散地放入一个足够大的空闲区。不要把“进程被分成段”误认为“主存也被切成段”。这一点在段页式里才改变：段页式的主存像分页一样划分为页框，每个段再被切成整数个页。

分段的地址空间是二维的：段号 + 段内偏移。程序员需要给出“哪个段、段内哪里”；分页的地址空间是一维的，页号和页内偏移由硬件从线性地址中切分，程序员看不到页。

二、段表与地址转换

每个进程有一张段表，每个段占一个段表项，段表项至少包含：

  • 段号（通常就是索引）；
  • 段长：用于越界检查；
  • 基址：该段在主存中的起始物理地址。

段表寄存器保存段表始址和段表长度。地址转换：

  1. 逻辑地址拆成“段号 S + 段内偏移 W”；
  2. 用 S 查段表，得到段长和基址；
  3. 若 W ≥ 段长，越界中断；
  4. 物理地址 = 基址 + W。

所以“段表项要存段长”不是多此一举：页的大小由系统固定，偏移天然不会超过一页；段的大小由程序决定，硬件必须拿段长做越界检查。

段共享怎么实现

段是逻辑单位，适合共享代码/只读数据。常见实现有两种：

  • 共享段表：系统维护一张共享段表，表项记录共享段名、段长、物理基址、共享计数、权限等；各进程的段表项指向这个共享表项（或直接复制其基址/段长）。进程 attach 时计数加 1，detach 时减 1，计数为 0 才真正回收。
  • 各自段表项指向同一物理段：每个进程的段表里都有一条段表项，段长相同、基址指向同一个物理段；共享关系靠操作系统维护的共享计数/权限表保证，回收时也要等最后一个进程释放。

共享段一般要求代码/只读数据，权限要按“可读可执行、不可写”设置；如果共享段可写，还要考虑一致性和同步。分页也能共享（多个页表项指向同一页框），但共享粒度是固定页，不如按逻辑段共享自然。

三、分段地址转换例子

逻辑地址（段号 2，段内偏移 30）：

  1. 查段表第 2 项：段长 120K，基址 120K；
  2. 30 < 120K，不越界；
  3. 物理地址 = 120K + 30 = 122880 + 30 = 122910。

如果偏移 ≥ 段长，说明访问越过了该段的末尾，硬件产生越界中断，操作系统通常终止进程。分段地址是二维的：段号 + 段内偏移；分页地址是一维的：页号 + 页内偏移。

四、分段的共享与保护

段是逻辑单位，所以“共享代码段、保护数据段”很自然：多个进程的段表可以指向同一个共享代码段的物理区，但各自的数据段私有。段表项可以带读/写/执行权限，越权访问触发保护异常。

分页也能共享（多个页表项指向同一页框），但页没有逻辑含义，共享的粒度是固定页；分段按逻辑段共享，粒度更自然，但段长不等会带来外部碎片。

五、段页式：先分段再分页

段页式先把用户程序按逻辑分成段，再把每个段分成大小固定的页；主存划分成页框。这样既保留分段的逻辑结构，又用分页消除段的外部碎片。

  • 每个进程一张段表，段表项至少含段号、页表长度、页表始址；
  • 每个段一张页表，页表项含页号、页框号；
  • 逻辑地址 = 段号 S | 页号 P | 页内偏移 W；
  • 转换：S 查段表→页表始址；P 查页表→页框号；页框号 + W = 物理地址。

段页式的段表项不再存“段长 + 段始址”，而是存“页表长度 + 页表始址”：段长可以由“页表长度 × 页大小”得到（最后一页可能没用满），段在物理上也不再是一整块连续区，而是由若干页框拼成。主存在这里像分页一样划分页框，不再像纯分段那样“对主存不做划分”。

段页式也可以用 TLB：TLB 表项存放“段号 + 页号 → 物理块号”的映射，命中时直接得到页框号，跳过段表和页表两次查表；未命中才走“段表 → 页表”。进程切换时同样要刷新 TLB 或用 ASID 区分。

地址空间维度：分页是一维的（一个线性地址，硬件切页号/偏移）；分段和段页式是二维的（段号 + 段内偏移，段内再分页只是实现细节，程序员仍按“段 + 偏移”看）。这是三者最容易被忽略的区别。

七、易错点与收束

  • “分段会划分主存”：分段是对进程逻辑地址空间划分；主存按空闲区分配，不预先按段切。
  • “段表项只存基址”：还要存段长用于越界检查；段页式的段表项还要存页表长度/始址。
  • “段页式只查一次表”：先查段表找页表，再查页表找页框，至少两次。
  • “分段没有碎片”：分段按不等长段分配，会产生外部碎片。

把这一节收成一句话：分段是“按逻辑切”，段表给段长+基址；段页式是“先分段再分页”，段表找页表、页表找页框。
