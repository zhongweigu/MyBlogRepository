考点12-拓扑排序

拓扑排序是对有向无环图的顶点的一种排序：若存在一条从顶点 A 到顶点 B 的路径，则排序中 B 一定出现在 A 的后面。

求法就是反复"挑入度为 0 的顶点"：

  1. 在有向图里挑一个入度为 0 的顶点，输出它；
  2. 从图中删掉这个顶点以及它的所有出边（这些边的终点入度随之减 1）；
  3. 重复这两步，直到图中再也找不到入度为 0 的顶点。

收尾的时候看输出的顶点数：比图里的顶点数少，说明图中存在环（环上的顶点入度永远降不到 0）；一个不差，输出的序列就是一个拓扑序列。

六条常考结论：

  • 拓扑序列可能不唯一——同时有好几个入度为 0 的顶点时，先挑谁都可以；
  • 有向图里只要有环，就不存在拓扑序列；
  • 拓扑序列唯一 ⇒ 入度为 0 的顶点、出度为 0 的顶点都各只有一个；
  • 顶点数大于 1 的强连通图不能做拓扑排序（强连通就意味着有环）；
  • 序列里 A 排在 B 前面，不代表原图中就有 $A \to B$ 这条边；
  • 拓扑序列唯一，并不能唯一确定这张图。

一般实现（邻接表 + 栈）：

展开：基于邻接表的拓扑排序实现 
bool TopologicalSort(Graph G)
{
    InitStack(S);                        // 初始化栈，用来存放入度为 0 的顶点
    int i;
    for (i = 0; i < G.vexnum; i++)
        if (indegree[i] == 0)
            Push(S, i);                  // 把所有入度为 0 的顶点入栈
    int count = 0;                       // 计数：当前已经输出了多少个顶点
    while (!IsEmpty(S))                  // 栈不空，说明还有入度为 0 的顶点
    {
        Pop(S, i);                       // 栈顶元素出栈
        print[count++] = i;              // 输出顶点 i
        for (p = G.vertices[i].firstarc; p; p = p->nextarc)
        {
            v = p->adjvex;               // 把 i 的这条出边"删掉"：终点的入度减 1
            if (!(--indegree[v]))
                Push(S, v);              // 减到 0 就入栈
        }
    }
    if (count < G.vexnum)
        return false;                    // 输出的顶点不够：有向图里有回路
    else
        return true;                     // 拓扑排序成功
}

核心是那行 if (!(--indegree[v]))：删掉 $i$ 的一条出边，等价于把终点 $v$ 的入度减 1；减到 0 说明 $v$ 的前驱都已经输出，$v$ 可以入栈了。

count 则负责判环——环上的顶点入度永远降不到 0，进不了栈，最后 count < G.vexnum 就说明有环。

例题：【2012】（邻接矩阵下三角全零时的拓扑排序）

【2012】若用邻接矩阵存储有向图，矩阵中主对角线以下的元素均为零，则关于该图拓扑排序的结论是

  • A. 存在，且唯一
  • B. 存在，且不唯一
  • C. 存在，可能不唯一
  • D. 无法确定是否存在
查看答案解析

选 C（存在，可能不唯一）。

  • 一定存在：主对角线以下全为 0，也就是 $i > j$ 时 $A[i][j] = 0$——边只能从小号顶点指向大号顶点。图里不可能有环：沿着环走一圈，顶点编号只能一直变大，绕回起点就矛盾了。没有环，拓扑排序一定存在。
  • 但不一定唯一：一条边都没有的图（邻接矩阵全是 0，当然也满足"下三角全零"）随便什么顺序都是合法拓扑序；而如果图是一条链 $0 \to 1 \to \dots \to n-1$，顺序就被钉死了。所以只能说"存在，可能不唯一"。

例题：【2016】（邻接表存有向图，拓扑排序的时间复杂度）

【2016】若对 $n$ 个顶点、$e$ 条弧的有向图采用邻接表存储，则拓扑排序算法的时间复杂度是

  • A. $O(n)$
  • B. $O(n + e)$
  • C. $O(n^2)$
  • D. $O(ne)$
查看答案解析

选 B（$O(n + e)$）。 对着上面那段实现数：开头扫一遍所有顶点建初始栈，$O(n)$；之后每个顶点恰好进栈、出栈各一次，$O(n)$；每出栈一个顶点，顺着它的边表把所有出边扫一遍，所有边加起来是 $e$ 条，$O(e)$。合计 $O(n + e)$。

（用邻接矩阵就退化成 $O(n^2)$——每出栈一个顶点都得扫一整行才找得到它的出边，这正是选项 C 的来历。）

用有向无环图描述表达式

用有向无环图（DAG）表示表达式时，叶子结点是操作数、内部结点是运算符；两个结点只要代表同一个子表达式（运算符相同、参与运算的两部分也相同），就合并成一个结点。这么做的好处就是共享公共子表达式，结点数比表达式二叉树少得多。

画法四步：

步骤 做什么
① 把各个操作数不重复地排成一排，作为最底层的叶子
② 标出各个运算符的生效顺序
③ 按顺序分层加入运算符，每个运算符只作用于它下面已经画好的那部分
④ 从底向上逐层检查，把相同的子表达式合体成一个结点

以 $((a+b)*(b*(c+d))+(c+d)*e)*((c+d)*e)$ 为例，合体之后是这样：

原式里 c+d 出现了 3 次、(c+d)*e 出现了 2 次，合体后各只留一个结点，a~e 这些操作数也只画一次——这就是 DAG 比二叉树省结点的地方。

合并时的两条判据：依据是"同一个子表达式"（运算符相同、两部分也相同），合完不能打乱原来的运算先后。

例题：【2019】（DAG 描述表达式至少要几个顶点）

【2019】用有向无环图描述表达式 $(x+y)((x+y)/x)$，需要的顶点个数至少是

  • A. 5
  • B. 6
  • C. 8
  • D. 9
查看答案解析

选 A（5）。 原式的运算分三层：最里面是 $x+y$，然后是 $(x+y)/x$，最后两者相乘。

顶点 = 每个操作数一个叶子 + 每个不同的子表达式一个内部结点：

  • 操作数：$x$、$y$，共 2 个；
  • 运算符：$+$（$x+y$）、$/$（$(x+y)/x$）、$*$（最外层的乘法），共 3 个。

$x+y$ 在原式里出现两次，DAG 只画一个结点；$x$ 既是 $x+y$ 的操作数、又是除法的除数，也只画一次。合计 $2 + 3 = 5$ 个，选 A。

考点15-关键路径

四个量，两个按事件算、两个按活动算：

量 怎么算
事件 $v_i$ 的最早发生时间 $v_e$ $v_e(\text{源点}) = 0$；$v_e(k) = \max\{\,v_e(j) + \text{Weight}(v_j, v_k)\,\}$，$v_k$ 是 $v_j$ 的任意后继
事件 $v_i$ 的最迟发生时间 $v_l$ $v_l(\text{汇点}) = v_e(\text{汇点})$；$v_l(k) = \min\{\,v_l(j) - \text{Weight}(v_k, v_j)\,\}$，$v_k$ 是 $v_j$ 的任意前驱
活动 $a_i$ 的最早开始时间 $e$ 该弧起点顶点的 $v_e$
活动 $a_i$ 的最迟开始时间 $l$ 该弧终点顶点的 $v_l$ 减去这条弧的权值

活动的时间余量就是 $l - e$：余量为 0（$l = e$）的活动叫关键活动，关键活动连起来就是关键路径。

六条常考结论：

  1. 活动的时间余量 $= l - e$；
  2. 关键活动的时间余量为 0（$l = e$），关键活动组成了关键路径；
  3. 关键路径可能不唯一；
  4. 关键路径就是持续时间最长（权值之和最大）的那条路径；
  5. 缩短关键路径，并不一定让整个工期加快： - 只有一条关键路径时，缩短它一定加快； - 有多条关键路径时，只缩短其中一条不一定加快——被缩短的那条就不再是关键路径了，工期还卡在另一条上； - 只有缩短所有关键路径上共有的某个关键活动，工期才会加快； - 反过来，延长任意一条关键路径上的关键活动，工期一定变慢；
  6. 求关键路径是以拓扑排序为基础的。

例题：【2013】（加快哪两个活动能缩短工期）

【2013】下列 AOE 网表示一项包含 8 个活动的工程。通过同时加快若干活动的进度可缩短整个工程的工期。在下列选项中，加快其进度就可缩短工程工期的是

  • A. c 和 e
  • B. d 和 c
  • C. f 和 d
  • D. f 和 h
查看答案解析

选 C（f 和 d）。

先算事件的时间参数（$v_e$ 从源点往后取 max，$v_l$ 从汇点往前取 min）：

事件 1 2 3 4 5 6
$v_e$ 0 12 8 21 18 27
$v_l$ 0 12 8 21 18 27

再用 $e$（弧起点的 $v_e$）和 $l$（弧终点的 $v_l$ 减弧权）算余量：只有 a 的余量不为 0（$l - e = 9$），b、d、c、e、f、g、h 的余量全是 0，都是关键活动。

于是关键路径有三条，长度都是 27：

  • 1→3→2→4→6：$b + d + c + g = 8 + 4 + 9 + 6 = 27$
  • 1→3→2→5→6：$b + d + e + h = 8 + 4 + 6 + 9 = 27$
  • 1→3→5→6：$b + f + h = 8 + 10 + 9 = 27$

工期被这三条同时卡着，只有让三条都变短才会缩短，所以逐个选项看"覆盖了哪几条关键路径"：

  • A（c、e）：c 只压到第 1 条、e 只压到第 2 条，第 3 条（b、f、h）没动 ✗
  • B（d、c）：d 压到第 1、2 条，第 3 条仍然没动 ✗
  • C（f、d）：d 压到第 1、2 条，f 压到第 3 条——三条全覆盖 ✓
  • D（f、h）：第 1 条（b、d、c、g）完全没被碰到 ✗

所以选 C。

例题：【2011】（上三角存储还原邻接矩阵，求关键路径）

【2011】已知有 6 个顶点（编号为 0~5）的有向带权图 G，其邻接矩阵 A 为上三角矩阵，按行为主序（行优先）保存在如下的一维数组中：

4, 6, ∞, ∞, ∞, 5, ∞, ∞, ∞, 4, 3, ∞, ∞, 3, 3

要求：

1）写出图 G 的邻接矩阵 A。 2）画出有向带权图 G。 3）求图 G 的关键路径，并计算该关键路径的长度。

查看答案解析

1） 上三角只存 $i < j$ 的部分，按行切开正好是 $5 + 4 + 3 + 2 + 1 = 15$ 个数：第 0 行 5 个、第 1 行 4 个、第 2 行 3 个、第 3 行 2 个、第 4 行 1 个。

$$A = \begin{pmatrix} 0 & 4 & 6 & \infty & \infty & \infty \\ \infty & 0 & 5 & \infty & \infty & \infty \\ \infty & \infty & 0 & 4 & 3 & \infty \\ \infty & \infty & \infty & 0 & \infty & 3 \\ \infty & \infty & \infty & \infty & 0 & 3 \\ \infty & \infty & \infty & \infty & \infty & 0 \end{pmatrix}$$

（对角线记 0；下三角没有边，记 $\infty$。）

2） 从矩阵里读出的 7 条弧是 0→1（4）、0→2（6）、1→2（5）、2→3（4）、2→4（3）、3→5（3）、4→5（3）：

3）关键路径是 0→1→2→3→5，长度 16。

第一步：从源点往后推每个事件的最早发生时间 $v_e$（汇合点取 max，取"最晚到齐"的那条路）：

  • $v_e(0) = 0$
  • $v_e(1) = v_e(0) + 4 = 4$
  • $v_e(2) = \max\{v_e(0)+6,\ v_e(1)+5\} = \max\{6,\ 9\} = 9$（两条路进来，取长的）
  • $v_e(3) = v_e(2) + 4 = 13$
  • $v_e(4) = v_e(2) + 3 = 12$
  • $v_e(5) = \max\{v_e(3)+3,\ v_e(4)+3\} = \max\{16,\ 15\} = 16$（汇点，$v_e(5)$ 就是工期）

第二步：从汇点往前推导每个事件的最迟发生时间 $v_l$（分叉处取 min，取"最先卡住"的那条路；先令 $v_l(5) = v_e(5) = 16$）：

  • $v_l(4) = 16 - 3 = 13$
  • $v_l(3) = 16 - 3 = 13$
  • $v_l(2) = \min\{v_l(3)-4,\ v_l(4)-3\} = \min\{9,\ 10\} = 9$
  • $v_l(1) = v_l(2) - 5 = 4$
  • $v_l(0) = \min\{v_l(1)-4,\ v_l(2)-6\} = \min\{0,\ 3\} = 0$

两轮结果合起来：

事件 0 1 2 3 4 5
$v_e$ 0 4 9 13 12 16
$v_l$ 0 4 9 13 13 16

第三步：算每条弧（活动）的最早开始时间 $e$、最迟开始时间 $l$——$e$ 取弧起点的 $v_e$，$l$ 取弧终点的 $v_l$ 减去这条弧的权，两者之差就是余量：

弧 权 $e = v_e(\text{起点})$ $l = v_l(\text{终点}) - \text{权}$ 余量 $l - e$
0→1 4 0 $4 - 4 = 0$ 0
0→2 6 0 $9 - 6 = 3$ 3
1→2 5 4 $9 - 5 = 4$ 0
2→3 4 9 $13 - 4 = 9$ 0
2→4 3 9 $13 - 3 = 10$ 1
3→5 3 13 $16 - 3 = 13$ 0
4→5 3 12 $16 - 3 = 13$ 1

余量为 0 的四条弧 0→1、1→2、2→3、3→5 是关键活动，串起来就是关键路径 0→1→2→3→5，长度 $4 + 5 + 4 + 3 = 16$。经过 4 的那条支路（2→4、4→5）余量都是 1，不在关键路径上。
