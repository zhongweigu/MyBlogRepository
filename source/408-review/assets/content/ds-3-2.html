线索化

线索二叉树说的是物理结构：每个结点是 [lchild][lTag][data][rTag][rchild]，多出来的两个 tag 用来交代旁边的指针到底指什么。

  • tag = 0：指针指向孩子（还是原来那个二叉链表）；
  • tag = 1：指针指向前驱 / 后继（这就是"线索"）。

实现上不用另写一套遍历：在遍历的基础上，把输出语句换成线索化的核心代码就行。

展开：中序线索化的正确写法

线索化要沿用“左 → 根 → 右”的中序遍历顺序。核心代码里 pre 始终指向上一个访问过的结点，也就是当前结点的前驱；pre 一开始置成 NULL。

void InThread(BiTree p, BiTree &pre) {
    if (p == NULL) return;

    InThread(p->lchild, pre);      // 1. 递归线索化左子树

    if (p->lchild == NULL) {       // 2. 当前结点没有左孩子
        p->lchild = pre;           //    左指针指向前驱
        p->ltag = 1;
    }
    if (pre != NULL && pre->rchild == NULL) {
        pre->rchild = p;           //    前驱没有右孩子，右指针指向后继
        pre->rtag = 1;
    }
    pre = p;                       // 3. 当前结点成为下一个结点的前驱

    InThread(p->rchild, pre);      // 4. 递归线索化右子树
}

void CreateInThread(BiTree T) {
    BiTree pre = NULL;
    if (T != NULL) {
        InThread(T, pre);
        if (pre->rchild == NULL)   // 最后一个结点没有后继
            pre->rtag = 1;
    }
}

注意：必须先递归左子树，再改当前结点的左指针。如果先改 `p->lchild` 再递归，原左孩子就丢了；这正是迭代版最容易写错的地方。右子树在改完当前结点后递归，不受影响。

中序线索树里找前驱、找后继的两条规律：

  • 某个结点有右孩子时，它的后继是它右子树中最左下的结点；
  • 某个结点有左孩子时，它的前驱是它左子树中最右下的结点。
