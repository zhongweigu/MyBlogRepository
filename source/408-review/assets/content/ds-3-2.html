线索化

线索二叉树说的是物理结构：每个结点是 [lchild][lTag][data][rTag][rchild]，多出来的两个 tag 用来交代旁边的指针到底指什么。

  • tag = 0：指针指向孩子（还是原来那个二叉链表）；
  • tag = 1：指针指向前驱 / 后继（这就是"线索"）。

实现上不用另写一套遍历：在遍历的基础上，把输出语句换成线索化的核心代码就行。

展开：线索化的核心代码

核心代码里 pre 始终指向上一个访问过的结点，也就是当前结点的前驱；pre 一开始置成 NULL。

pre = NULL;
...
if (!p->lchild) {                 // 左孩子为空 → 左指针改指前驱
    p->lchild = pre;
    p->ltag = 1;
}
if (pre && !pre->rchild) {        // 前驱的右孩子为空 → 它的右指针改指后继 p
    pre->rchild = p;
    pre->rtag = 1;
}
pre = p;                          // 这个结点走完了，它就是下一个结点的前驱

填进前面的先序遍历，原本写 cout << p->data; 的位置就换成这段：

void PreOrderTraverse(BiTree T) {
    InitStack(S);
    BiTree p = T;
    BiTree q;
    BiTree pre = NULL;
    while (p || !StackEmpty(S)) {
        if (p) {
            if (!p->lchild) {
                p->lchild = pre;
                p->ltag = 1;
            }
            if (pre && !pre->rchild) {
                pre->rchild = p;
                pre->rtag = 1;
            }
            pre = p;
            Push(S, p);
            p = p->lchild;
        } else {
            Pop(S, q);
            p = q->rchild;
        }
    }
}

中序线索树里找前驱、找后继的两条规律：

  • 某个结点有右孩子时，它的后继是它右子树中最左下的结点；
  • 某个结点有左孩子时，它的前驱是它左子树中最右下的结点。

例题：【2014】（中序线索化后 X 的左右线索）

【2014】若对下图所示的二叉树进行中序线索化，则结点 X 的左、右线索指向的结点分别是

  • A. e, c
  • B. e, a
  • C. d, c
  • D. b, a
查看答案解析

选 D（b, a）。 中序遍历这棵树得到 e d b X a c：排在 X 前面的 b 是它的前驱，排在后面的 a 是它的后继。

X 是叶结点，左、右指针本来都空着，线索化时两个都要改成线索——左线索指向前驱 b、右线索指向后继 a，所以是 D。

例题：【2010】（哪棵是后序线索树）

【2010】下列线索二叉树中（用虚线表示线索），符合后序线索树定义的是（四个选项见下图）

查看答案解析

选 D。 这棵树的后序序列是 d b c a，按「左指针空就指前驱、右指针空就指后继」逐个数：

结点 空的指针 该指向谁
a 没有 左右都是真孩子，不产生线索
b 左 前驱 d
c 左、右 左指前驱 b、右指后继 a
d 左、右 左指针是后序第一个、没有前驱（仍是 NULL），右指后继 b

也就是说虚线该是「b 的左线索指 d、c 的左线索指 b、c 的右线索指 a、d 的右线索指 b」这四条，只有 D 全对得上。

另外三个都能挑出对不上的地方：A 把 d 的右线索指到了 c，B 里有两条线索都指向 a（后序里指向 a 的只该有 c 那一条），C 里 d 的右线索也指到了 c。

例题：下列关于二叉树的叙述中，哪个正确

下列关于二叉树的叙述中，正确的是

  • A. 若二叉树的先序遍历结果是 ABCD，则其中序遍历结果可以是 DABC
  • B. 如果二叉树的先序遍历序列和中序遍历序列的最后一个结点相同，那么该结点一定是整棵树最右侧的叶子结点
  • C. 要交换二叉树所有分支结点的左右子树，最好利用中序遍历作为框架解决
  • D. 删除一棵二叉树可以通过先序递归方式依次释放所有结点
查看答案解析

选 B。

  • A 错：先序 ABCD 定出根是 A。若中序是 DABC，那 A 左边只有 D（左子树）、右边是 BC（右子树），先序就应该是 A、D、BC 拼起来得 ADBC，和题给的 ABCD 对不上。
  • B 对：先序的最后一个结点，是从根出发「有右孩子就往右、没有右孩子才往左」走到底的那个；中序的最后一个结点是顺着右孩子走到底的最右下结点（它必然没有右孩子）。这两个位置要是同一个结点，它就连左孩子也不能有——否则先序的最后会拐进它的左子树里。所以它一定是最右侧的叶子结点。
  • C 错：交换左右子树用后序（先序也行）做框架都可以，唯独中序不行——中序的框架是「左、根、右」，把根的左右孩子换完再去遍历"左子树"时，走进去的已经是被换过来的原右子树，原左子树整条都被漏掉。
  • D 错：释放结点必须最后释放根，否则根的左右孩子指针一丢，剩下的结点再也找不到。所以要用后序递归，而不是先序。
