一、物理层四大特性

物理层接口规范通常从四个方面描述：

特性描述什么记忆
机械特性接插件的形状、尺寸、引脚数目/排列、固定和锁定方式机械看外形
电气特性各条线上电压范围、阻抗、传输速率等电气参数电气看电压
功能特性某条线上某一电平表示什么意义（数据/控制/定时）功能看意义
过程特性（规程特性）不同功能的各种可能事件的出现顺序过程看时序

“物理地址（MAC 地址）”不属于物理层规范，它是数据链路层的概念；这是 2018 年真题的考点。

二、传输介质

传输介质分导向介质（信号沿固体通路传播）和非导向介质（无线）：

  • 双绞线：两根绝缘铜线绞合，抵消部分电磁干扰；UTP/STP，以太网常用，约 100m；便宜、易施工。
  • 同轴电缆：内导体、绝缘层、外屏蔽层、护套；抗干扰较好，早期以太网/有线电视使用；比双绞线粗、贵。
  • 光纤：光在纤芯中全反射；单模芯径小、激光、远距离，多模芯径大、LED、较短距离；带宽高、抗电磁干扰。
  • 无线：无线电/微波/红外；无需布线、覆盖灵活，但受干扰、遮挡、频谱管制影响。

三、中继器

中继器（repeater）工作在物理层，把衰减/畸变的数字信号整形、再生后转发，从而扩展传输距离。它只有两个端口，只识别比特，不识别帧、MAC 地址或 IP 地址。

  • “再生”不是“模拟放大”：中继器重新产生干净的数字波形；放大器只是把模拟信号幅度放大，噪声也一起放大。
  • 中继器两端的网段仍属于同一个冲突域、同一个广播域。

四、集线器 Hub

集线器本质是多端口中继器：一个端口进入的数据会被复制/转发到所有其他端口。它工作在物理层，不学习 MAC 地址，也不做路径选择。

  • 所有端口在同一冲突域；同一时刻只能一个端口发送，因此通常是半双工。
  • 所有端口在同一广播域；广播会从所有端口发出。
  • 用 Hub 组网时，带宽由所有端口共享，冲突会降低有效吞吐。

五、冲突域、广播域与 5-4-3

冲突域是可能发生介质访问冲突的范围；广播域是广播帧能到达的范围。物理层设备不改变这两个范围：

设备隔离冲突域隔离广播域工作层次
中继器 / Hub否否物理层
交换机是（每端口）否（默认）数据链路层
路由器是是网络层

5-4-3 规则：早期 10Mb/s 以太网中，用 4 个中继器串联的 5 段通信介质，只有 3 段可以连接计算机。它是冲突域/时延限制的经验规则，现代交换式网络不再机械套用。

六、以太网标准命名

以太网标准名通常写成 10BaseT、100BaseTX、1000BaseSX 这种形式，三段分别表示“速率 / 信号方式 / 介质”。

名称速率信号/介质读法
10Base510Mb/s基带、粗同轴10M、基带、粗缆（500m）
10Base210Mb/s基带、细同轴10M、基带、细缆（约185m）
10BaseT10Mb/s基带、双绞线T=Twisted pair；约100m
100BaseTX100Mb/s基带、双绞线TX=双绞线（两对）
100BaseFX100Mb/s基带、光纤F=Fiber
1000BaseT1Gb/s基带、双绞线千兆双绞线
1000BaseSX / LX1Gb/s基带、光纤S=短波，L=长波
10GBaseT / SR / LR10Gb/s双绞线 / 光纤T 双绞线，S 短波，L 长波

读法：第一个数字是比特率（Mb/s 或 Gb/s，注意 1000Base 是 1Gb/s）；Base 表示基带传输（Broad 才是宽带）；后缀表示介质/波长：T=双绞线，F=光纤，S=短波，L=长波，X 是双绞线/光纤的细分代号。

命名只说明标准的目标速率和介质类型，不保证实际吞吐量达到标称值；双绞线还有 Cat5e/Cat6 等类别，距离和速率要一起看。

七、易错点与收束

  • “中继器放大模拟信号”：中继器再生数字信号；放大器放大模拟信号。
  • “Hub 隔离冲突域”：Hub 所有端口在同一冲突域；交换机才隔离冲突域。
  • “光纤一定用激光”：单模常用激光，多模常用 LED，不能一概而论。
  • “物理地址属于物理层”：物理地址是 MAC 层/数据链路层概念。
  • “无线没有介质”：空气/真空就是传播介质，只是非导向。

收束：物理层规定“接口怎么接、信号怎么传、介质怎么选、设备怎么扩距离”；它只处理比特，不处理帧、MAC 地址和 IP 地址。
