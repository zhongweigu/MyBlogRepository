审题不是“看懂材料”，而是“判断命题人想让你讨论什么”。看懂材料只完成了一半；另一半是从材料里挑出那个能被论证、又足够宏大的主题。这一篇给一套七步流程，每步都配判断标准和易错点。

第 1 步：判题型，也判任务

先看两件事，不要混在一起：

判什么怎么判影响什么
材料类型有画/漫画 → 图画；有坐标轴/表格/百分比 → 图表；只有一段话 → 文字；两种以上 → 混合决定第一段用哪套起手句
题目任务圈动词：describe / interpret / comment / give your comments / suggest决定三段各写什么，尤其第二段是“原因”还是“意义”
节次A 节（约 100 词，应用文）还是 B 节（160–200 词，短文）决定格式、语气、字数

易错：把“描述 + 解读 + 评论”当成“描述 + 描述 + 描述”。官方对 2023 年图画题的表述是“文章应包含以下三部分内容：第一部分简单描述题目所给图画……第二部分解读图画含意……第三部分根据解读出的主题思想展开议论”。三个动词，三种写法，不能都写成描述。

第 2 步：抓材料里的“命题人线索”

材料里的信息不是等价的。以下五类，优先级从高到低：

  1. 人物话语。2023 年“咱们村的龙舟赛越来越热闹了”、2021 年“你自己不是喜欢吗？那就足够了”、2022 年“去听听肯定有好处”——这些话就是命题人塞给你的立意方向。官方对 2023 年的原话是“特别是人物话语的意义和指向性”。
  2. 标题与图注。2020 年图画下方的“习惯”、2024 年柱状图的“某市近三年公园数量”、2025 年表格的“平均每百户年末主要耐用消费品拥有量”。标题往往就是主题的范围。
  3. 对比与反差。2020 年两幅图（尽早完成 vs 拖到最后）、2026 年“接受 39.3% vs 不接受 27.9%”。对比处就是论点所在。
  4. 极值。图表里最大/最小/变化最大的那一项。2026 年安全 46.3% 最高，2025 年空调增幅最大。
  5. 单位与范围。per hundred households、in China、among consumers surveyed。单位决定你能不能正确描述，范围决定主题词的限定语。

易错：只抓“图里有什么”，不抓“图里为什么有这个”。2024 年图里既有跑步的人，也有“市民健身区”的牌子，还有“家门口”三个字——命题人要的是“便利 + 民生”，不是“跑步有益健康”。

第 3 步：从细节问出“含义”

做法很简单：对每个关键细节问一句“这说明什么”，连问两层，不要停在第一层。

材料细节第一层（表面）第二层（含义）
2024：家门口、真不错、公园数量 406→670公园变多了，居民满意公共空间进入日常生活，城市建设回应民生需求 → 宜居城市
2023：村里赛龙舟、老人感叹“越来越热闹”传统活动有人看乡土习俗重新聚集人气，乡村公共文化生活恢复 → 乡村文化振兴
2025：空调 75.2→145.9，接近翻倍家电拥有量上升发展成果转化为居住舒适度与生活品质 → 高质量发展 / 民生福祉
2020：女孩“尽早完成才放心”，男孩“不到最后不动手”两个人习惯不同时间管理与自我约束的差异 → 自律
2022：“不是我们专业的，听了也没用” vs “去听听肯定有好处”对讲座态度不同是否愿意接触专业之外的知识 → 终身学习

判断标准：第二层必须能同时解释“材料里的具体细节”和“一个公共议题”。只能解释细节，是描述；只能解释议题，是贴标签。

第 4 步：把含义归到七类价值观

B 语料库的七类（和谐、富强、文明、敬业、友善、爱国、诚信）不是政治课分类，而是“主题词检索目录”。归类的目的只有一个：快速找到可用的语料槽。

材料在讲优先归到可用槽位
公共设施、居住环境、民生保障、人与自然和谐livable city development / sustainable urban development / public health
经济、科技、基础设施、国家实力富强high-quality development / innovation-driven development / public service improvement
文化、教育、读书、文明素养文明cultural heritage preservation / quality education / building a learning society
工作、学习、行动力、坚持敬业talent development / a spirit of hard work and dedication
互助、关爱、社区、弱势群体友善volunteer service development / social harmony
国家认同、文化认同、民族自豪爱国cultural identity development / patriotic education
信任、诚实、承诺、商业道德诚信social credit system development / market integrity

易错：一份材料只归一类，然后硬套。2026 年养老机器人同时属于富强（科技）与和谐（养老），主题词要把两类接起来；2024 年公园同时属于和谐（宜居）与富强（公共服务）。允许跨类，但主题词只能有一个。

第 5 步：把主题词写成 3–5 个词

主题词不是“中心思想”，是一个能反复填入模板的名词短语。三条标准：

  1. 能填进三个位置不变形。第一段“the significance of ___”、第二段“___ has attracted attention”、第三段“when ___ guides action”。填进去读一遍，通顺才合格。
  2. 3–5 个词。太短（development）空，太长（the improvement of people's living standards through economic development）第三段会拖垮。
  3. 有动词性或明确的动作指向。building livable cities / cultural revitalization in rural areas / lifelong learning / self-discipline 都比 livable city / culture / learning 更能“指导行动”。

向上与向下。主题词有两个失败方向：

  • 太低：停在材料表层。2023 写“传统文化”，2024 写“环保”，2025 写“家电变多”。
  • 太高：材料撑不住。2020 写“民族复兴”，2022 写“人才强国”。

判断方法：把主题词放回材料，问“图里哪一处能支撑它”。支撑不了，就往下走一层；只能支撑“描述”，就往上走一层。2020 年的正确路径是：习惯 → 时间管理 → 自律（而不是敬业 → 奋斗 → 民族复兴）。

永远准备一个退路。七年真题里，每年都有一版“无脑套写”换用更简单的主题词：2026 technological development、2025 improving living standards、2024 improving city life、2023 keeping village traditions alive、2022 learning beyond one's major、2021 valuing traditional culture、2020 developing good habits。退路不是低分，是“主题词更容易接住材料”的保险。

第 6 步：定结构，选版本

情况选哪版理由
目标 17+，语料背了 3 类以上满分版（9 空）个人—政策—社会—战略四层，论据最具体
目标 13–16，语料只背了核心词简化版（5 空）成果与能力固定，减少现场决策
只剩 1–2 周速通版（5 句）骨架最短，靠第⑤句的机构撑“实证”
材料极个人化（如 2020 习惯）简化版或速通版满分版的“政策领域 + 战略”容易硬凑
混合材料（2024、2026）满分版或速通标准需要两套描述句 + 一个主题词，骨架要稳

结构固定为三段，但每段内部要有“上升”：第一段从描述到主题，第二段从个人到社会，第三段从总结到倡导。不要把第二段写成“个人、个人、个人”。

第 7 步：用三个问题自检

  1. 偏题没有？把主题词遮住，只看第一段描述，能不能猜出主题词？猜不出，说明描述与主题脱节。
  2. 漏任务没有？题目要求 describe / interpret / comment，三段是否各承担一个？A 节三个内容要点是否都写了？
  3. 拔高没有？把主题词换成更小的一层，文章是否更有说服力？如果是，说明原来拔高了。

附：8 分钟审题训练法

C 拿一年真题，只做四件事，限时 8 分钟：

  1. 写材料类型 + 题目任务（1 分钟）。
  2. 抄下三个关键细节（人物话语 / 标题 / 极值）（2 分钟）。
  3. 写“细节 → 含义”两行（2 分钟）。
  4. 写主题词 + 退路 + 选版本（3 分钟）。

写完对照 真题页 的“审题与主题”三栏。连续练七年，审题会变成条件反射：看到材料先找“人物话语/标题/极值”，再问“这属于哪类价值”，最后落成“3–5 个词”。

一句话总结：审题 = 判题型与任务 + 抓命题人线索 + 问出两层含义 + 归价值观 + 写 3–5 词主题 + 选版本 + 三问自检。七步里，第 2 步和第 5 步决定分数。
