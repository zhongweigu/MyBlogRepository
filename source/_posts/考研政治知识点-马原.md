# 专题一、导论

**社会根源**：==资本主义==经济社会的发展。

**阶级基础**：<u>无产阶级作为独立的政治力量登上历史舞台，迫切需要科学理论指导</u>。

**三个直接理论来源**：

- ==德国古典哲学==——黑格尔的辩证法（合理内核）、费尔巴哈的唯物主义（基本内核）
- ==英国古典政治经济学==——亚当·斯密、大卫·李嘉图
- ==法国空想社会主义==——圣西门、傅立叶、欧文

**一个自然科学前提**：==细胞学说==、==能量守恒与转化定律==、==生物进化论==（三大发现）。

**基本特征**

- ==科学性==：以事实为依据、以规律为对象，以实践为检验标准
- ==革命性==：彻底的批判精神，鲜明的无产阶级立场
- ==实践性==：==区别于其他理论的显著特征==；<u>实践观点是马克思主义首要的和基本的观点</u>
- ==人民性==：人民至上的政治立场，是马克思主义的==本质属性==
- ==发展性==：与时俱进、开放发展

一句话：<u>以实践为基础的科学性与革命性的统一</u>。

# 专题二、世界的物质性

**哲学基本问题**（恩格斯）：<u>思维和存在的关系问题是哲学的基本问题</u>。包括两个方面：

- **第一性**：思维和存在何者为第一性——谁是本原
- **同一性**：思维能否正确认识存在——世界是否可知

**哲学的划分**

| 划分依据 | 派别 |
| --- | --- |
| 世界本原（何者为第一性） | ==唯物主义== / ==唯心主义== |
| 是否可知（有无同一性） | ==可知论== / ==不可知论== |
| 世界怎样存在 | ==辩证法== / ==形而上学== |
| 社会历史 | ==历史唯物主义== / ==历史唯心主义== |

**唯心主义的两种形态**

- ==主观唯心主义==：把人的主观精神（心、感觉、经验、意志）当作世界本原。如王阳明「心外无物」、贝克莱「存在就是被感知」
- ==客观唯心主义==：把客观精神（理、理念、绝对精神、上帝）当作世界本原。如朱熹「理在事先」、黑格尔「绝对精神」

---

**物质范畴**（列宁）

<u>物质是标志客观实在的哲学范畴，这种客观实在是人通过感觉感知的，它不依赖于我们的感觉而存在，为我们的感觉所复写、摄影、反映</u>。

- 不依赖意识而存在的==客观实在==
- 唯一特性：==客观实在性==
- <u>只有尚未认识之物，没有不可认识之物</u>

**物质与运动**：运动是物质的==根本属性==和==存在方式==，物质和运动==不可分割==。

- 设想无物质的运动 → ==唯心主义==
- 设想无运动的物质 → ==形而上学==

**运动与静止**：运动是==绝对的、无条件的==，静止是==相对的、有条件的==；静止是运动的特殊状态。

- 相互依赖、相互包含、相互渗透——==动中有静，静中有动==
- 反对：形而上学不变论、相对主义诡辩论

**物质运动与时空**：时空是运动着的物质的==基本存在形式==。

- ==客观性==
- 时间==一维==（不可逆），空间==三维==
- 物质运动总是在一定时空中进行
- <u>时空的客观实在性是绝对的，具体特性是相对的</u>
- 具体事物的时空有限，整个物质世界的时空无限

---

**物质世界的二重化**：物质世界二重化为==自在世界==（天然自然）与==人类世界==（属人世界），==实践==是二者分化与统一的基础。

**世界的物质统一性**

<u>世界的本原是物质，世界统一于物质</u>。

- 物质世界的统一是==多样性的统一==
- 是辩证唯物主义==最基本、最核心==的观点
- 意义：一切从实际出发、实事求是

# 专题三、物质与意识的辩证关系

**物质决定意识**

- **起源**：意识是==自然界长期发展==的产物，经历三个决定性环节——无机物的反应特性 → 低等生物的刺激感应性 → 动物的感觉和心理 → 人的意识；同时是==社会历史发展==的产物，==劳动==起决定作用（促进人脑形成、推动语言产生）
- **本质**：意识是==人脑的机能和属性==，是==客观世界的主观映象==，是==客观内容和主观形式的统一==

**几个易错点**

- 高等动物有感觉和心理，但==没有意识==
- 意识不能脱离物质；<u>人脑是意识的器官，不是意识的源泉</u>，意识的源泉是==客观世界==
- <u>意识无论如何都是客观世界的主观映像</u>，错误的意识是对客观存在的歪曲反映

---

**意识对物质具有反作用**（意识的能动作用）

- ==目的性和计划性==
- ==创造性==
- <u>指导实践、改造客观世界</u>——能动性的突出表现
- ==调控人的行为和生理活动==

**主观能动性与客观规律性的辩证统一**

- **规律**：<u>事物运动发展中固有的、本质的、必然的、稳定的联系</u>
- 尊重客观规律是正确发挥主观能动性的==前提==；充分发挥主观能动性是认识和利用客观规律的==必要条件==
- 正确发挥主观能动性：从==实际出发==（前提）、==实践==（根本途径）、一定的==物质条件和物质手段==

---

**自然规律与社会规律**

- **区别**：自然规律在==盲目的、无意识的力量==相互作用中起作用；社会规律通过==人有意识、有目的的活动==实现，离不开人的实践
- **联系**：二者都是==客观的==，社会规律不能脱离自然规律，二者相互交织
- **认识难度**：<u>认识社会规律比认识自然规律更困难</u>

# 专题四、事物的普遍联系和变化发展

**总观点**：<u>联系和发展的观点是唯物辩证法的总观点，集中体现了唯物辩证法的总特征</u>。

**联系的特点**

- ==客观性==：联系是事物本身所固有的，不以人的意志为转移
- ==普遍性==：事物内部各要素相互联系、事物之间相互联系、世界是相互联系的统一整体
- ==多样性==：直接联系与间接联系、内部联系与外部联系、本质联系与非本质联系、必然联系与偶然联系
- ==条件性==：条件支持或制约事物发展；条件可以改变；改变和创造条件必须==尊重客观规律==

**易错**：自在事物的联系与人为事物的联系==都具有客观性==——"联系都是人为的""联系都是主观意志赋予的""一切联系都在实践中形成""任何事物之间都能建立直接联系"，均错。

**发展的实质**：<u>发展是事物变化中前进的、上升的运动，实质是新事物的产生和旧事物的灭亡</u>。

**新事物不可战胜**

- 有新的要素、结构和功能，适应已经变化了的环境和条件
- 是对旧事物的==扬弃==，添加了旧事物所不能容纳的新内容
- 社会历史领域：符合==人民群众==的利益和要求，得到人民群众拥护

**过程论**：世界是==过程的集合体==，一切事物都有产生、发展和灭亡的历史；<u>凡是在历史上产生的，都要在历史上灭亡</u>。

**判断新旧事物**：不看形式新旧、出现时间先后，而看是否==合乎历史前进方向、具有远大前途==。

# 专题五、对立统一规律

**地位**：对立统一规律是唯物辩证法的==实质和核心==。

- 揭示了事物普遍联系的==根本内容==和变化发展的==内在动力==，回答「事物为什么发展」
- 是贯穿==量变质变规律==、==否定之否定规律==和唯物辩证法基本范畴的==中心线索==，是理解它们的「钥匙」
- 提供了认识世界和改造世界的根本方法——==矛盾分析方法==

**矛盾**：<u>反映事物内部或事物之间对立统一关系的哲学范畴</u>。对立属性即==斗争性==，统一属性即==同一性==。

- 斗争性==无条件的、绝对的==；同一性==有条件的、相对的==
- 同一性以差别和对立为前提；斗争性寓于同一性之中，同一性通过斗争性来体现
- 二者==不能孤立存在==，相互结合、共同推动事物变化发展
- ==和谐==是矛盾的特殊表现形式，不是矛盾的绝对同一；和谐是相对的、有条件的

**矛盾的普遍性与特殊性**

- 普遍性：==无处不在，无时不有==
- 特殊性：具体事物的矛盾及其各个方面，在发展的不同阶段各有特点
- 共性==无条件的、绝对的==，个性==有条件的、相对的==；<u>共性寓于个性之中</u>，没有离开个性的共性
- 认识规律：由个别到一般，再由一般到个别

**矛盾力量的不平衡性**

- 主要矛盾：诸多矛盾中处于==支配地位==、对事物发展起决定作用
- 矛盾的主要方面：每一对矛盾中处于==支配地位==、起主导作用
- <u>事物的性质由主要矛盾的主要方面所决定</u>

# 专题六、量变质变规律

**质、量、度**

- ==质==：一事物区别于其他事物的内在规定性；<u>质和事物的存在直接同一</u>
- ==量==：规模、程度、速度等可以用数量关系表示的规定性；一定范围内的量的增减不影响某物之为某物
- ==度==：保持事物质的稳定性的数量界限，两端叫==关节点（临界点）==，超出度此物就转化为他物 → 方法论：==适度原则==
- 认识质是认识的起点和基础，认识量使认识==深化和精确化==

**量变与质变**

- ==量变==：保持质的相对稳定性的不显著变化，体现发展的渐进性和连续性
- ==质变==：事物性质的根本变化，体现发展渐进过程和连续性的中断
- 关系：量变是质变的==必要准备==，质变是量变的==必然结果==并为新的量变开辟道路；二者==相互渗透==（总的量变中有阶段性和局部性的部分质变，质变中有新质的量的扩张）

**两个判断**

- 区分量变与质变的根本标志：<u>事物的变化是否超出度</u>
- <u>量变达到一定程度必然引起质变，单纯的量变不会永远持续下去</u>

# 专题七、否定之否定规律

**辩证否定观**

- 否定是==事物的自我否定==、自我发展，是事物内部矛盾运动的结果
- 是==发展的环节==：经过否定，旧事物才能向新事物转变
- 是==联系的环节==：新事物孕育于旧事物，新旧事物通过否定联系起来
- 实质是==扬弃==：既批判又继承，既克服消极因素又保留积极因素

**形而上学否定观**：否定是==外在的、主观任意的==否定，是绝对的否定，不包含肯定（如人踩死一只虫子，是外部否定，不是事物的自我否定）。

**否定之否定**

- 两次否定、三个阶段：==肯定—否定—否定之否定==
- 发展呈现==周期性==，不同周期的交替使发展呈==波浪式前进、螺旋式上升==
- 揭示==前进性与曲折性的统一==：不是直线式前进，而是螺旋式上升

**易错**：否定之否定阶段仿佛是向出发点的「回复」，但这是==更高阶段的回复==（古代朴素辩证法—形而上学—唯物辩证法）。

# 专题八、联系和发展的基本环节（五对范畴）

五对范畴都是==辩证的对立统一关系==：既相互区别（对立），又相互依存、相互渗透、相互转化、相互作用（统一）。

**内容与形式**

- 内容决定形式；形式反作用于内容（适合的推动，不适合的阻碍），但形式==没有决定作用==
- 同一内容可有多种形式，同一形式也可表现不同内容

**本质与现象**

- 本质：一般的、普遍的、相对稳定的、深藏内部，靠==理性思维==把握
- 现象：个别的、具体的、多变易逝的、表面外显，靠==感官==感知
- 本质决定现象，现象表现本质；<u>不表现为现象的本质、不表现本质的现象都不存在</u>
- 真象与假象都是==客观==的，假象从反面歪曲地表现本质；==假象≠错觉==（错觉是主观的）

**原因与结果**

- 原因在前、结果在后，不能混淆颠倒；没有无果之因，也没有无因之果
- 同一现象在不同联系中，可以是原因也可以是结果

**必然与偶然**

- 必然通过偶然表现出来并为自己开辟道路；偶然背后隐藏着必然
- ==必然性与本质是同等程度的范畴==，揭示的都是事物内在的联系
- 偶然不是可有可无的因素；不能说「偶然通过必然表现出来」（说反了）

**现实与可能**

- 现实是当下的客观存在，可能是事物潜在的趋势
- 区分可能与不可能：现实中有无==根据和条件==
- 现实的可能与抽象的可能：根据和条件是否==充分==
- <u>发展就是现实与可能相互转化的过程</u>

**易错（干扰项）**

- 本质随着人们认识的变化而改变（×）
- 不可能通过现象去认识事物的本质（×）
- 只要充分发挥主观能动性，不可能就会转化为可能（×）
- 历史过程不包含任何偶然因素（×）

# 专题九、唯物辩证法是认识世界和改造世界的根本方法

**客观辩证法与主观辩证法**

- 主观辩证法是客观辩证法在人的思维中的==反映==；二者本质统一，表现形式不同
- 客观辩证法采取==外部必然性==的形式，主观辩证法采取==观念的、逻辑的==形式
- 关系：==反映与被反映==

**六大思维能力**：==辩证思维==、==历史思维==、==系统思维==、==战略思维==、==底线思维==、==创新思维==。

**系统观念**：系统是由相互联系、相互作用的若干要素组成的具有==稳定结构和特定功能==的有机整体。<u>坚持系统观念，就是要把事物放在普遍联系的系统中来把握</u>。

# 专题十、实践

**实践的本质**：<u>人类能动地改造世界的社会性的物质活动</u>。

**三个基本特征**

- ==客观实在性==：直接现实性是其具体表现，能把主观的东西变为客观现实
- ==自觉能动性==：有意识、有目的，不同于动物本能的、被动的适应性活动
- ==社会历史性==：内容、性质、范围、水平、方式都受社会历史条件制约

**基本结构**

- ==实践主体==：有一定主体能力、从事现实社会实践活动的人
- ==实践客体==：实践活动所指向的对象
- ==实践中介==：物质性工具系统 + 语言符号工具系统，主客体依靠中介相互作用
- 主客体关系：实践关系、认识关系、价值关系，其中==实践关系最根本==

**易错**：<u>客体不等于客观</u>——客观事物只有被纳入实践活动范围、成为实践指向的对象，才成为现实的实践客体；最基本的实践活动是==物质生产==，不是科学实验；各种「统一的基础」都是==实践==，不是认识活动。

**三种基本形式**

- ==物质生产实践==：人类最基本的实践活动
- ==社会政治实践==
- ==科学文化实践==：创造精神文化产品（科学、艺术、教育等），不是纯粹的意识过程
- 派生形式：==虚拟实践==（网络世界，交互性、开放性、间接性）

**判断标准**：一种活动能否称为实践，看它是否超出了纯粹的意识活动，是否改变了除实践主体意识状态之外的其他存在物的状态。

# 专题十一、认识的本质

**两条认识路线**

- ==唯心主义先验论==：从思想和感觉到物；认识先于实践经验（"生而知之""认识即回忆"）
- ==唯物主义反映论==：从物到感觉和思想；认识是主体对客体的反映，知识来自后天接触实际

**两种反映论**

- ==旧唯物主义==（直观的、消极被动的反映论）：离开实践考察认识问题；不了解认识的辩证本性，认为认识是一次性完成的
- ==辩证唯物主义==（实践基础上能动的反映论）：把==实践观点==引入认识论；把==辩证法==应用于反映论，把认识看作由不知到知、由浅入深的能动过程

**认识的本质**：<u>主体在实践基础上对客体的能动反映</u>。

- ==反映特性（摹写性）==：以客观事物为原型和摹本
- ==能动创造性==：不是照镜子式的原物映现，而是思维中的能动创造（如透过现象看本质）
- 二者是==同一本质的两个方面==，认识是摹写性与创造性的统一

**易错**：警惕"直观""机械"的提法——对事物本来面目做直观反映、意识是对存在的直观反映、一切观念都是现实的模仿、意识建构认识对象，均错。

# 专题十二、认识的两次飞跃以及实践与认识的辩证运动

**第一次飞跃：实践 → 认识**

| 对比 | 感性认识 | 理性认识 |
| --- | --- | --- |
| 内容 | 初级阶段，感官直接感受，反映现象和外部联系 | 高级阶段，借助抽象思维，反映本质、全体和内部联系 |
| 形式 | 感觉、知觉、表象 | 概念、判断、推理 |
| 特点 | 直接性、具体性 | 间接性、抽象性 |
| 评价 | 不深刻（≠不可靠） | 深刻 |

- 关系：理性认识依赖于感性认识（感性是起点、必经阶段）；感性认识有待于深化为理性认识；二者==相互渗透、相互包含==——感性中有理性，理性中有感性
- 两个条件：① 获取十分丰富和合乎实际的感性材料 ② 对感性材料==去粗取精、去伪存真、由此及彼、由表及里==
- 非理性因素：情感、意志（狭义），联想、想象、猜测、直觉、顿悟、灵感（广义），起==激活、驱动==作用；理性因素起==指导、解释、预见==作用

**第二次飞跃：认识 → 实践**，比第一次飞跃==更重要==

- 认识世界的目的是改造世界
- 真理只有在实践中才能得到检验和发展

**实践与认识的辩证运动**：实践、认识、再实践、再认识，==循环往复以至无穷==，呈波浪式前进、螺旋式上升。

- 具体过程：感性—理性—实践；总过程：实践—认识—再实践—再认识

**易错**：不能说第一次飞跃更重要；理论对实践的指导有正确与错误之分。

# 专题十三、真理

**真理的客观性**

- 真理：<u>标志主观与客观相符合的哲学范畴，是对客观事物及其规律的正确反映</u>；形式主观、内容客观
- ==客观性==是真理的本质属性，凡真理都是客观真理
- ==一元性==：同一条件下对特定客体的真理性认识只有一个；认识多元，真理一元

**易错**：真理≠客观实在（真理是一种认识）；"多数人承认的就是真理""有用即真理"都是主观真理论；真理是==内容上的一元性与形式上的多样性==的统一。

**真理的绝对性和相对性**

- ==绝对性==：主客观统一的确定性 + 发展的无限性；任何真理都与谬误有原则界限
- ==相对性==：一定条件下的正确认识总是有限度、不完善的，有待扩展和深化
- 统一：相互依存、相互包含（绝对之中有相对，相对之中有绝对）；==真理的相对性向绝对性转化==（方向不能倒过来，也不是相互转化）
- 根源：人类认识能力的==无限性与有限性==的矛盾

**真理与谬误**

- 在确定对象和范围内，对立是==绝对的==——一种认识不能既是真理又是谬误
- 对立又是==相对的==，一定条件下可以相互转化

**实践是检验真理的唯一标准**

- 依据：==真理的本性==（主客观相符合）和==实践的特点==（直接现实性）
- ==逻辑证明==起重要补充作用，但不能取代实践
- 主观真理标准论：圣人权威、自己的观念、多数人的意见、"有用"或"效果"

# 专题十四、价值

**价值的本质**：<u>反映主体和客体之间意义关系的哲学范畴</u>，是客体对个人、群体乃至整个社会的生活和活动所具有的意义。

- 错误观点：==客观主义价值论==（价值是客体固有、与主体无关）、==主观主义价值论==（价值是主体的欲望情感兴趣、与客体无关）
- 正确观点：价值离不开==主体的需要==，也离不开==客体的特性==，既具有主体性特征，又具有客观基础

**四个基本特性**

- ==主体性==：以主体为中心；同一客体对不同主体价值不同；价值关系不是自然的现成关系，靠主体在实践中创造
- ==客观性==：价值独立于人们的认识和评价，认识评价可以反映但不能创造或消灭价值
- ==多维性==：同一客体相对于主体的不同需要产生不同价值
- ==社会历史性==：随实践和历史发展，人们的价值判断也改变

**价值评价**

- 是==对客观价值关系的主观反映==，以自身需要为内在尺度，评价的差异性无法避免
- 知识性认识以求==真==为目的，价值评价以求==善、美==为目的
- 评价结果与主体直接相关；其正确与否依赖于对==客体状况和主体需要==的认识
- 有科学与非科学之别：以==真理==为根据，以==最广大人民的需要和利益==为根本

**真理与价值的统一**：成功的实践是==真理尺度和价值尺度==的统一，是==合规律性和合目的性==的统一。

**最高标准**：是否推动社会历史进步、是否符合社会发展趋势、是否维护和满足最广大人民的需要和根本利益。

# 专题十五、认识世界和改造世界

**根本目的**：认识世界的根本目的在于<u>改造世界</u>；认识世界和改造世界统一的基础是==实践==。

**两个改造**：改造客观世界与改造主观世界相互促进——只有在改造客观世界的实践中才能深入改造主观世界，只有认真改造主观世界才能更好地改造客观世界。

**从必然走向自由**

- ==必然==：即规律性，不依赖人的意识而存在，人不能摆脱其制约
- ==自由==：对必然的认识 + 对客观世界的改造；有认识条件和实践条件；<u>认识必然只是取得自由的前提，只有利用必然改造世界、达到预想目的，自由才能真正实现</u>
- 自由是==相对的==，不是绝对的
- 两种错误：==宿命论==（消极顺应自然、抹杀自由的可能性）、==唯意志论==（否定客观必然性、夸大意志自由）
