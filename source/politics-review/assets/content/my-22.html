简单再生产与扩大再生产

  • 简单再生产：生产在原有规模的基础上重复进行（剩余价值全部用于消费）。就其实质而言，是物质资料再生产和资本主义生产关系再生产的统一。
  • 扩大再生产：资本家将获得剩余价值的一部分转化为资本，用以购买追加的生产资料和劳动力，使生产在扩大规模上重复进行。资本主义再生产的特点是扩大再生产；资本积累是资本主义扩大再生产的源泉。

资本积累

定义：把剩余价值转化为资本，或者说剩余价值的资本化。

本质：资本家不断地利用无偿占有的、工人创造的剩余价值来扩大自己的资本规模，从而进一步扩大和加强对工人的剥削和统治。

源泉：剩余价值。

规模取决于四个因素：

  1. 资本家对工人的剥削程度；
  2. 劳动生产率的高低；
  3. 所用资本和所费资本之间的差额；
  4. 资本家预付资本的大小。

后果：加剧社会的两极分化；是资本主义社会失业现象产生的根源。

历史趋势：资本主义制度的必然灭亡和社会主义制度的必然胜利。

六个「源泉」提法，别串

政经的选择题很喜欢在「源泉」上换主语。下面六句要能一一对上：

判断对应
价值的唯一源泉抽象劳动
使用价值的源泉（但不是唯一源泉）具体劳动
价值的源泉（就劳动力而言）劳动力商品的使用价值
剩余价值产生的唯一源泉雇佣劳动者的剩余劳动
资本主义扩大再生产的源泉资本积累
资本积累的源泉剩余价值

资本积累 ≠ 资本原始积累

  • 资本原始积累：资本主义生产方式确立以前，用暴力手段剥夺农民土地、掠夺货币财富的过程，是「血与火」的历史。
  • 资本积累：资本主义生产方式确立之后，把剩余价值重新转化为资本的过程。

两者都扩大资本规模，但一个靠暴力剥夺，一个靠剩余价值资本化，不能混用。

资本有机构成

  • 资本的技术构成：由生产的技术水平所决定的生产资料和劳动力之间的比例。
  • 资本的价值构成：不变资本（c）和可变资本（v）之间的比例。
  • 资本的有机构成：由资本的技术构成决定并反映技术构成变化的资本价值构成，即 c : v。

在资本主义生产过程中，资本有机构成的提高是一般趋势，这是由资本的本性决定的。

注意限定条件：只有那些「由资本的技术构成决定并反映技术构成变化的」价值构成，才叫有机构成。如果只是生产资料涨价，只改变了价值构成，不涉及技术构成，更不涉及有机构成。

相对过剩人口

资本有机构成提高，可变资本的相对量减少，资本对劳动力的需求日益相对地减少，结果不可避免地造成大批工人失业，形成相对过剩人口——劳动力供给超过了资本的需求。

相对过剩人口的三种形式：流动的过剩人口、潜在的过剩人口、停滞的过剩人口。

资本循环

产业资本循环经历三个阶段，对应三种职能形式：

阶段职能形式变化发挥的职能
购买阶段货币资本 → 生产资本为生产剩余价值准备条件
生产阶段生产资本 → 商品资本生产剩余价值
售卖阶段商品资本 → 货币资本实现剩余价值

产业资本运动的基本前提条件：三种职能形式必须在空间上并存（并存性），在时间上继起（继起性）。

资本周转

资本周转：周而复始、不断反复着的资本循环。影响资本周转速度的关键因素有两个：资本周转的时间；生产资本的固定资本和流动资本的构成。

由于每次资本周转带来的剩余价值是固定的，加快资本周转速度不会提高剩余价值率，但能够提高年剩余价值率和年剩余价值量。

划分依据内容
不变资本 / 可变资本在剩余价值生产过程中的作用不同全部生产资料 / 劳动力
固定资本 / 流动资本在价值流通和周转方式上的不同厂房、机器等劳动资料 / 原材料、燃料等＋劳动力

易错点

  • 把「资本积累的源泉」写成「剩余劳动」——剩余劳动是剩余价值的源泉，资本积累的源泉是剩余价值本身。
  • 把「扩大再生产的源泉」写成「剩余价值」——扩大再生产的源泉是资本积累。
  • 混淆「所用资本」与「所费资本」：所用资本是全部预付资本，所费资本是实际消耗并转移到产品中的部分。
  • 把资本积累的后果只记成「失业」——还有两极分化；历史趋势则是资本主义灭亡和社会主义胜利。
  • 把「价值构成的变化」都当成「有机构成的变化」——只有由技术构成引起并反映其变化的才算。
  • 认为加快资本周转能提高剩余价值率——提高的是年剩余价值率和年剩余价值量。
