> 依据：[`408-visualization.md`](rules/408-visualization.md)、[`408-knowledge-base.md`](rules/408-knowledge-base.md)。
>
> 范围：当前 **93 个考点**。逐个看正文结构、已有 `img` / Mermaid / HTML-CSS 图 / 表格，再判断“还值不值得画”。
>
> 结论口径：
> - **已足够**：现有图、表、Mermaid 或 HTML-CSS 图已经覆盖核心关系，不再增加装饰图。
> - **可补 P1**：文字明显吃亏，补一张图能直接修正理解或形成考试直觉。
> - **可补 P2**：有收益，但优先级低于 P1；可在后续批次做。
> - **不需要**：公式、定义或短表已足够，强行画图会变成装饰。
