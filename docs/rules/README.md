# 408 规则文件索引

本目录是 408 知识库更新、知识库与复习卡片的长期规则入口。规则不在对话里临时生效，而是每次任务开始时从文件读取。

## 三份主规则

| 文件 | 负责 | 什么时候必须读 |
| --- | --- | --- |
| [`408-knowledge-update.md`](408-knowledge-update.md) | 用户提供图片/文字/文件/教材/课件/笔记/真题后的资料识别、对照、整合、更新与汇报流程 | 任何“用户发来资料，更新知识库”的任务开始时 |
| [`408-knowledge-base.md`](408-knowledge-base.md) | 知识库内容的编写、扩展、修订、图文组织、来源核实、更新后检查 | 任何新增/修改/删除 408 知识库正文、图示、例题说明、章节结构时 |
| [`408-review-cards.md`](408-review-cards.md) | 从知识库提取复习卡片、卡片粒度/提问/答案、每日复习、知识库变化后的增量同步 | 任何复习卡片/每日复习/知识点库同步任务时 |

## 任务路由

- **用户发来资料，要更新知识库**：先读 `408-knowledge-update.md`，再读 `408-knowledge-base.md`；改完按 `408-review-cards.md` 检查卡片同步。
- **不涉及新资料，只改已有知识库**：先读 `408-knowledge-base.md`；改完仍必须检查卡片同步。
- **每日复习 / 抽卡 / 改卡片 / 卡片同步**：只读 `408-review-cards.md`，以现有卡片和知识库为数据源；**不要**在每日复习任务里重写知识库或重新做知识库重构。
- **只改站点的路由、样式、JS、缓存版本**：读 `docs/408-review-maintenance.md` 和 `AGENTS.md` §20；如果同时改内容/卡片，再读对应规则。
- **考研政治复习台**：不在本目录范围内，按 `AGENTS.md` §21 和 `docs/politics-review-maintenance.md` 执行。

## 优先级

同一事项出现冲突时：

1. 用户在当前任务中的明确指令。
2. `408-knowledge-update.md`（资料接入流程/是否先确认）。
3. `408-review-cards.md`（仅卡片/每日复习/同步事项）。
4. `408-knowledge-base.md`（仅知识库内容标准）。
5. `AGENTS.md` §20/§22 与 `docs/408-review-maintenance.md` 的项目结构、格式、站点约定。
6. 一般写作习惯。

规则文件的职责不同，不按“新文件覆盖旧文件”处理。资料接入流程与内容标准冲突时，先按本索引判断职责；仍不能判断时暂停并报告。项目实现与规范不一致时，先报告冲突，不要为了贴合规则擅自重构现有内容或站点。

## 冲突处理

- 发现三份规则对同一内容要求不一致：先以本索引的职责边界判断；仍不能判断时暂停修改并报告，不自行选一个执行。
- 发现旧规则与新规则冲突：保留旧规则中仍然有效的项目约定；新规则只在其职责范围内生效。具体保留/修改清单见 `AGENTS.md` §23。
- 发现规范与当前站点实现不一致（例如卡片字段尚未落地）：把差异记录为待迁移项，不在日常复习或普通内容更新中顺手重构。
