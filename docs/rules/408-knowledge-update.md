# 408 知识库更新规则（资料接入流程）

> 本文件是长期规则，不是某次任务的临时说明。
>
> **触发条件：** 用户提供图片、文字、文件、教材、课件、笔记、真题或其他学习资料，要求更新 408 知识库时。
>
> **任务开始前必须读取：**
> 1. 本文件（资料接入流程）；
> 2. [`408-knowledge-base.md`](408-knowledge-base.md)（内容标准与写法）；
> 3. 更新完成后按 [`408-review-cards.md`](408-review-cards.md) 检查卡片同步。
>
> 本文件负责“资料怎样进入知识库”；内容准确性、详略、图文标准以 `408-knowledge-base.md` 为准。

## 1. 理解资料

先识别和理解用户提供的全部资料，提取其中有价值的知识内容。

- 图片不仅要识别文字，还要理解公式、图表、结构图、流程图、时序图和状态图所表达的信息。
- 文字、PDF、课件、笔记要区分：教材原文、教师推导、个人总结、题目与解析、补充观点。
- 多个文件之间要交叉核对，不能只看其中一个文件。
- 对模糊、缺失、遮挡、无法确认的内容，**不得自行猜测**；标记“待核实”并向用户说明。
- 资料中的题目要判断是完整题目还是知识点示例；完整题目按题库规则处理，不混进正文当普通段落。

## 2. 对照现有知识库

更新前先查找知识库中相关章节和已有内容，判断本次资料属于：

- 新增；
- 补充；
- 纠错；
- 优化表达；
- 与已有内容重复；
- 与已有内容冲突。

要求：

- 不要重复收录已有内容；
- 不要未经核实就覆盖原有知识；
- 先读对应 `content/<topic-id>.html`、`data/{ds,coa,os}.js` 和已有图示；
- 找到最合适的归属章节和讲解位置，不机械追加到章节末尾；
- 若资料与已有内容冲突，先列出冲突点和依据，不能为了“统一”强行消除真实差异。

## 3. 遵循 408 考试要求

以当前适用的考研 408 大纲为边界：

- 大纲内知识要准确、完整、适度深入；
- 不能因真题出现频率低就随意省略；
- 辅助理解的超纲背景可以补充，但必须明确标注“拓展”；
- 无法确认是否属于大纲的内容，标记“待核实”，不自行断言；
- 不把某道真题的偶然考法当成知识全部；
- 不根据少数真题随意缩小大纲范围。

## 4. 整理并融入知识库

按现有知识库的学科、章节和知识体系整合到正确位置：

- 不要机械复制原文，要理解后重新组织；
- 逻辑清晰、详略得当、概念与实例结合；
- 保留必要定义、前提条件、适用范围、公式、推导、算法步骤、因果关系、边界条件和易错点；
- 简单内容不过度展开，复杂原理和过程必须解释充分；
- 适合可视化的内容补结构图、流程图、时序图、状态图、数据结构图、地址映射图或对比图；
- 图示必须准确，并与正文互相对应；图片要落到 `assets/textbook/` 或 `assets/img/`，在对应段落插入并配图注；
- 用户提供的图片若清晰准确可直接使用；若不清晰、缺信息或与正文不一致，先提出修正建议，不凭模糊内容猜测。

项目落点：

- 考点长文：`source/408-review/assets/content/<topic-id>.html`
- 考点索引/速记：`source/408-review/assets/js-vN/data/{ds,coa,os}.js`
- 图片：`source/408-review/assets/textbook/` 或 `assets/img/`
- 真题：`questions*.js`，正文不保留完整例题与答案解析
- 站点结构/构建：按 `docs/408-review-maintenance.md` 和 `AGENTS.md` §20

## 5. 同步复习卡片

知识库是知识内容的权威来源，复习卡片是知识库的结构化提取。

每次更新知识库后必须：

1. 读取 [`408-review-cards.md`](408-review-cards.md) 的“知识库变更后的卡片同步”；
2. 识别受影响的卡片：新增、修改、拆分、合并或废弃；
3. 更新 `data/review-cards.js` 中对应的卡片；
4. 保留稳定 ID、`aliases`、关联关系和原始来源；
5. 不因内容更新清空或覆盖学习数据（`localStorage` 的 `review408.v1`）。

禁止：

- 只改知识库，不检查卡片；
- 每次更新都全量重建卡片；
- 因局部补充删除或覆盖未受影响的卡片；
- 删除旧卡片而不保留 ID/别名映射。

## 6. 保护现有内容

以**增量更新**为原则：

- 尽可能保留已有的正确内容；
- 不要无故重建整个章节或整个知识库；
- 不要为了插入新内容随意删除已有内容；
- 不要在没有充分理由时大规模改写成熟内容；
- 重大修改要记录原因和影响范围。

涉及以下操作时，**必须先说明方案和风险，等待用户确认后再执行**：

- 大规模修改；
- 批量删除；
- 覆盖原内容；
- 知识结构调整；
- 数据库/schema 变更；
- 历史数据迁移。

## 7. 更新后检查

完成后逐项检查：

- 内容是否符合 408 大纲；
- 专业术语、公式、单位、条件是否准确；
- 是否存在逻辑错误、重复或冲突；
- 公式、推导、算法步骤、边界条件是否完整；
- 图示是否准确、图文是否一致；
- 引用/来源是否可靠；
- 复习卡片是否已同步；
- 稳定 ID、别名和历史数据是否保留；
- 构建和页面是否正常（若涉及站点文件）。

没有实际执行的操作，不得声称已经完成。

## 8. 简要汇报

每次更新完成后，简要说明：

- 新增、补充、修正或优化了哪些内容；
- 更新了哪些章节或文件；
- 相关复习卡片如何调整；
- 是否存在需要用户确认的问题。

## 与其他规则的关系

- 本文件是**资料接入与更新流程**；
- `408-knowledge-base.md` 是**内容标准**（写什么、写多深、怎么组织、图文规范）；
- `408-review-cards.md` 是**卡片提取与同步标准**；
- 三者职责不同，不互相替代。

**总原则：以现有知识库为基础，以 408 考试要求为边界，以准确完整为目标，持续进行有组织的增量更新，并保持知识库、复习卡片和历史复习记录的一致性。**
